## 复现方法

1. `node scripts/qa-web-session.mjs`：在系统临时目录创建独立 SQLite 与本机 AI 模拟服务；测试地址固定为 127.0.0.1:30002。
2. `node scripts/qa-http-checks.mjs`：对独立服务运行 HTTP 矩阵。`qa-security-checks.mjs` 使用本轮指定的 QA 数据及编号，需保留该临时目录才能重放，不得改指向正式数据库。
3. `npm run test:v1-all`：逐项隔离运行全部已登记回归；本轮新增请求边界后登记数为 78。
