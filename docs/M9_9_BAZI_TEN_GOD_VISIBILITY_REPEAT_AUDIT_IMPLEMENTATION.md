# M9-9 岁运十神组合与显隐重复证据审计实施说明

## 1. 阶段目标

M9-9 在 M9-8 动态十神版本之上，建立“位置重复”审计层。程序回答：

- 同一个天干分别出现在哪些原局、大运、流年位置；
- 每个位置属于表层天干、地支藏干还是日主参照；
- 同一个十神分别出现在哪些表层或藏干位置；
- 当前构成跨层表层同干、表层与藏干同见、跨层藏干同见还是流年大运同见；
- 重复簇中的表层位置是否共同参与 M9-6 天干关系证据。

本阶段只审计位置和证据连接，不裁决透干、通根、坐根、藏干引动、旺衰、喜忌、吉凶或事件。

## 2. 数据链路

```text
确定性原局四柱
   ↓
M9-6 表层跨层干支关系证据
   ↓
M9-8 大运／流年表层与藏干十神
   ↓
M9-9 同干簇 + 同十神簇 + 表层证据连接
```

M9-9 不自行重新排盘或计算动态十神。每个版本绑定命盘、M9-6 关系审计和 M9-8 动态十神版本及指纹。

## 3. 位置模型

每个位置保存：

- 原局、大运或流年层级；
- 原局柱位或动态节点；
- 天干；
- 十神；
- 表层、藏干或日主参照；
- 藏干所属地支；
- 本气、中气或余气；
- 固定方法边界。

官方 `lunar-java` 的 `EightChar` 接口分别提供柱天干十神和地支藏干十神，并明确藏干结果可以包含一至三个元素。M9-9 沿用这种数据分离方式，不把天干十神和藏干十神压成一个无位置信息的数组。

## 4. 日主参照

原局日柱天干是所有十神计算的参照。它在两个视图中的处理不同：

### 4.1 同干视图

日主可以作为“日主参照”位置参与同干簇。例如丙日主遇丙流年时，可记录两个位置都是丙。

### 4.2 同十神视图

日主参照不计为比肩。只有原局其他柱、大运、流年或藏干相对日主确认为比肩时，才进入比肩簇。

这样避免把“命主自身”和“相对日主的同类角色”重复混算。

## 5. 重复簇生成条件

一个重复簇必须同时满足：

1. 至少存在两个位置；
2. 至少一个位置来自大运或流年动态层；
3. 同干簇的天干完全相同，或同十神簇的十神完全相同；
4. 所有位置来自当前真实时间片段。

纯原局内部的重复不会单独进入 M9-9，避免把静态命盘信息重复搬入每个流年结果。

## 6. 四种位置模式

| 模式 | 确定性条件 | 不能推出 |
| --- | --- | --- |
| 跨层表层同干 | 相同天干在两个以上层级的表层／日主参照出现 | 力量叠加、旺衰增强 |
| 表层与藏干同见 | 相同天干同时存在表层和藏干位置 | 透干、通根、坐根、引动 |
| 跨层藏干同见 | 相同天干出现在两个以上层级的藏干 | 藏干发动、力量翻倍 |
| 流年与大运同见 | 相同天干或十神同时存在流年和大运位置 | 事件必然叠加或重复发生 |

一个簇可以同时命中多种模式。模式是位置标签，不是互斥分类，也没有优先级。

## 7. 表层证据连接

重复不等于连接。只有下列条件全部满足时，簇才附带 M9-6 连接：

- 上游证据领域是天干；
- 证据参与节点与簇内位置的节点 ID 一致；
- 证据参与符号与位置天干一致；
- 至少两个簇内表层／日主参照位置共同参与同一条证据。

藏干不是 M9-6 表层关系参与节点，因此：

- 纯藏干重复不会生成连接；
- 表层与藏干同见不会自动生成连接；
- 连接只表示这些表层节点共同参与已有天干关系，不表示力量或作用结果。

## 8. 跨运分段

M9-9 继承 M9-8 的实际片段：

```text
交运前片段：原局 + 流年位置
交运后片段：原局 + 流年位置 + 新大运位置
```

两个片段独立分组。交运后的大运位置不会倒灌到交运前，也不会把两个片段的计数相加为权重。

## 12. 来源与方法边界

- [6tail lunar-java `EightChar` 官方实现](https://github.com/6tail/lunar-java/blob/master/src/main/java/com/nlf/calendar/EightChar.java)：用于核对天干十神与地支藏干十神分离返回的接口口径；
- M9-6 关系证据版本：用于精确表层参与节点连接；
- M9-8 动态十神版本：用于大运、流年角色和藏干位置。

“同干、同十神、显隐同见”是传统命理数据的结构化位置描述，不是现代科学因果结论，也不自动具备预测能力。
