# 动态紫微八字合参深化：主题四化与跨层结构复核

2026-10-16，北京时间 UTC+08:00。

入口是合参中心已有双盘内的“动态阶段”，选择综合、事业、感情、财运或学习，再选择流年／流月及观察时刻。阶段双盘依据下新增“动态双盘作用条件复核”，提供紫微主题、八字关系、双侧并列及规则来源四个视图。应用与保存阶段均不调用 AI。

## 本轮能力

紫微复用已定位的流年、流月四化。每层分别列本命主题宫与当前阶段主题宫映射，以本命地支坐标检查四化落点是否在各主题锚点的本宫、对宫或三方。同一四化可以关联多个锚点，全部保留，不叠加权重。未定位的落宫不补造；未命中不等于主题没有其他条件或存在相反结论。当前快照没有大限四化数组，因此本轮只保留大限背景，不额外计算大限四化或飞化链。

八字把原局已知柱、当前可用大运、精确立春流年与可选节令月作为节点，复用既有纯节点关系审计目录。记录跨层天干同类、生克、五合及地支合冲刑害，三合、三会、三刑必须成员齐全；原局内部关系不在本清单范围内。每条关系保留实际参与层、柱位、符号、规则与限制，不套用全年代表点或其他时间片段的效力结论。

当前大运、年、月表干和藏干十神分别列出，按已有主题目录标记观察入口。主题标签不裁定喜忌、人物身份、藏干透出或引动；未命中主题目录的角色同样保留。

双侧并列只解释两套规则各自的年月分界、长期阶段、主题入口及待核条件，不生成跨体系作用边，不按关系条数、相似文字或方法数量计票。四化与十神不能相互替换，两侧相近表述不构成独立事实互证。

## 时间与资料限制

沿用初版固定 UTC+08:00 墙钟、精确秒及前闭后开区间。紫微按观察日定位农历阶段，八字按精确立春／十二节和实际交运区间定位；不再次校正出生太阳时，不受浏览器时区影响。年层不补月、日、时，月层不补流日、流时。

首运前不加入第一运；八步运表之后不循环或延长。大运不可用时保留撤回原因。出生时间未知时不补时柱、不补精确起运，紫微主题位置保持子时试排参考。若观察在未知时刻的出生当天，复核状态为 `birth_time_unconfirmed`，个人节点、关系和主题十神索引均撤回；日历及紫微试排仍可查看，但不能宣称已对本人适用。

阶段键继续包含方法版本、层级及精确时刻，主题在数据库查询范围内独立隔离。旧阶段按保存的完整键读取原事实，不补复核字段，不用当前预览替换旧报告引用。相同观察条件显式重新应用会建立当前规则的预览，不覆写旧版本。

新报告逐章校验真实依据：紫微章须有 `ziwei:dynamic:review:`，八字章须有 `bazi:dynamic:review:`，共同观察、差异及行动章各须同时有两侧复核引用。引用不存在、错侧或只用旧动态定位引用时拒绝发布，保留已完成报告。提示版本依据实际保存的复核能力选择。

数据库仍为 v56，无新增迁移。继续复用账号数据库隔离、同源写入校验、私有不缓存、固定事实指纹、过期生成回收及迟到任务保护。客户端提交的伪造复核结果不进入保存快照。
