# 六爻用神与作用路径条件复核

2026-10-16（北京时间 UTC+08:00）。承接个人化择日岁运连接，按命理深化顺序继续六爻。入口仍为 `/liuyao`，数据库仍为 v56，无新增迁移；本轮未提交或推送远程。

## 用户可以做什么

新建占问时明确占问对象或六亲，保存后在“卦象与依据 → 六爻条件复核 → 用神作用证据链”查看四个视图：

| 视图 | 作用 |
| --- | --- |
| 候选对照 | 按原爻位保留多个候选，比较明动、静爻、伏神、月日和空冲合条件；仍可在新建时明确手选用神 |
| 作用路径 | 围绕正在查看的候选，逐一核对来源、五行方向和双方自身条件；查看候选不会改变已保存取用 |
| 共同发动 | 查看实际明动的忌生元、元生用，以及仇生忌、忌克用结构；相反链可并存 |
| 规则来源 | 查看原典入口及本阶段实现边界 |

展开两侧条件可以看到来源自身的回头克、变爻空破、生扶入口及目标承受条件。静爻、暗动候选和伏神不会被自动当作明动来源，变爻只保留在本位原动爻内。

新占问的 AI 对话增加“作用证据链”快捷问题，回复引用随该占问保存的候选、节点或共同发动依据。没有候选时先提示明确对象，不猜测自由占问文本中的用神。

## 规则实现与来源

本轮将已有五行、月日动变和飞伏条件连接为可核对路径，没有引入生克评分、自动优选或完整有效性裁决。多现按保存爻位保序；即使一位候选的生扶入口较多，也不会由程序替用户取用。

- 来源与用神的五行关系分别表示同类、生用、克用、用生来源和用克来源。仇神表示克元、生忌的类别，不冒充直接克用；箭头按实际生克方向显示，同五行只表示同类。
- 原明动爻的本位回头生作为生扶入口，回头克及变爻空破作为来源自身制约；相反条件一并保留，不因存在生用路径而略去。
- 忌元同动只识别两个原明动来源形成的接续相生；原忌克用关系继续保留，不自动认定贪生忘克、化解或生扶成功。
- 仇忌同动只识别实际来源形成的生忌克用连接，不宣告实际伤害或现实事件结果；多个链路不能投票、计分、抵消或优先裁决。
- 共同发动的两个来源必须实际明动，目标用神本身可以静、动或伏；伏神目标仍保留飞伏和是否出伏的待核条件。

依据沿用《增删卜易》的[用神章](https://zh.wikisource.org/wiki/增刪卜易/8)、[元忌仇类别章](https://zh.wikisource.org/wiki/增刪卜易/9)、[元忌衰旺及同动条件章](https://zh.wikisource.org/wiki/增刪卜易/10)、[动变生克冲合章](https://zh.wikisource.org/wiki/增刪卜易/15)和[旬空章](https://zh.wikisource.org/wiki/增刪卜易/26)。本轮重新核对了元忌衰旺和旬空章节；原典确定性断语及个案事件结果没有转写成程序结论。页面将来源与本阶段实现范围并列。

`liuyaoPromptVersionFor()` 根据保存内容选择能力：完整新版使用 v3；上一版条件快照使用原 v2；无复核的基础旧盘使用 v1。缺失或未知作用版本退回基础条件能力，未知条件版本退回基础装卦能力，不补算或声称存在新版事实。读取、问答及备份恢复均不改写旧盘。

服务端仍只消费原始起卦输入、明确对象及可选爻位。客户端伪造结果、用户标识或作用对象无法覆盖重算结果或跨账号写入；所有访问使用当前账号业务库，响应私有且不缓存，同源写入约束保持。没有新增公共分享接口。
