## 本轮实现

- 新增“旺衰前提、逐格复核、扶抑取用、调候取用、通关与病药”五个视图，按需展开，复用现有紧凑布局。
- 月令格局逐一消费已保存的格局条件矩阵，保留全部候选、来源干、透出条件、支持、风险及对应救应；不再让旧解释基线的首个候选覆盖其余路径。
- 建禄、月劫、阳刃明确采用另查财官食杀的入口；月令同气五行不直接列成补偏喜用。
- 扶抑从当前静态旺衰证据标签派生生扶、泄耗制或暂缓方向，展示四柱完整性、月令、实际藏根、反向与阻碍线索。最终旺衰、承载及特殊格局适用前提仍独立保留待核。
- 调候复用上一阶段的节令月及月内分支，只列当前适用干，分别展示主要、配合、条件支线、透藏位置与效力待核。
- 五条通关桥接分别列木土火、火金土、土水金、金木水、水火木的位置。日干在对峙参照中纳入，取用位置中仍不重复充当候选。两方是否势均对峙及桥接实际效力始终保留待核；病药法不擅自指定“药”。
- 五行汇总只展示扶抑、调候的条件方向，格局来源另列。同一五行在两法出现不叠加置信度；调候元素未落入扶抑集合，也不直接标为冲突或忌神。
