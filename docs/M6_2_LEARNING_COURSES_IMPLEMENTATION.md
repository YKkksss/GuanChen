# M6-2 课程与章节系统实施说明

> 完成时间：2026-08-17
> 范围：学习中心、首条入门课程、章节前置关系、确定性小测、学习进度与答题记录

## 1. 阶段目标

M6-2 将上一阶段的“在真实命盘上逐宫学习”扩展为独立的章节式课程。用户不需要先提问 AI，也可以沿着固定路径学习命盘结构；刷新页面或退出项目后，课程位置、章节状态与最佳成绩仍能恢复。

本阶段首条课程为《紫微斗数命盘结构入门》，只教授可复核的结构识别方法，不将单星断语、现实事件或运势预测写成入门标准答案。

## 2. 课程内容来源

课程内容分为三层：

1. 项目排盘引擎和类型契约提供宫位、星曜、命身宫、四化与空宫等程序事实。
2. 项目已收录的《骨髓赋》段落提供读盘顺序、三方关系与空宫借对宫的古籍参考。
3. M6 学习方法论提供先事实后解释、本命与运限分层、传统文化与现实事实分离等教学边界。

每章保存知识点 ID 和来源 ID，页面可以跳转到项目古籍库中的具体段落。课程内容版本为 `chart-foundation-course-v1`。

## 3. 七章学习路径

1. 先建立宫位坐标。
2. 识别命宫与身宫。
3. 分层读取星曜。
4. 建立三方四正。
5. 检查本命四化。
6. 处理空宫与借对宫。
7. 区分本命与运限。

除第一章外，每章以前一章完成为前置条件。用户可以查看课程目录，但不能绕过前置章节开始答题。

## 4. 确定性小测

每章包含不少于两道单选题或判断题。题目、选项、正确答案、解释和来源均由静态课程内容定义，服务端使用固定规则评分，不调用 AI。

首版采用全部答对后通过：

- 未通过时保留本章学习中状态。
- 允许重复作答。
- 保存最佳成绩，不因后续低分覆盖。
- 通过后解锁下一章。
- 每次尝试独立保存，便于后续生成错题本和复习计划。

## 5. 数据持久化

SQLite 第 15 版迁移新增：

### `learning_progress`

- 课程 ID 与章节 ID。
- `in_progress` 或 `completed` 状态。
- 最佳成绩和答题次数。
- 最近一次答案。
- 开始、完成和最近访问时间。

同一课程同一章节只有一条进度记录。课程最近位置由最近更新的章节推导。

### `learning_attempts`

- 课程 ID 与章节 ID。
- 本次得分和是否通过。
- 原始答案。
- 每题评分结果与依据说明。
- 提交时间。

课程正文不写入数据库，避免内容升级后存在多份不一致副本。

## 6. 页面与接口

页面：

- `/learn`：学习中心与课程总进度。
- `/learn/ziwei-chart-foundation`：课程目录、章节状态与课程依据。
- `/learn/ziwei-chart-foundation/[lesson]`：章节正文、常见错误、来源和小测。

接口：

- `GET /api/learning/courses`
- `GET /api/learning/courses/[courseId]/progress`
- `PUT /api/learning/courses/[courseId]/lessons/[lessonId]/progress`
- `POST /api/learning/courses/[courseId]/lessons/[lessonId]/attempts`

首页和单人命盘页均新增学习中心入口。

## 7. 验收与测试

`npm run test:learning-courses` 覆盖：

- 七章顺序和前置关系。
- 知识点和来源契约。
- 固定答案评分。
- 未完成前置章节时禁止越级。
- 失败后重试与最佳成绩。
- 学习进度、最近位置和答题历史。
- SQLite 第 15 版迁移。
