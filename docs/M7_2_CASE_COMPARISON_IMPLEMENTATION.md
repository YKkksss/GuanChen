# M7-2 匿名案例与大限对比实施文档

## 1. 阶段目标

M7-2 将匿名案例库从“单案例学习”升级为“多案例结构辨析”。本阶段完成两条确定性对比路径：

- 两个不同匿名教学案例的整盘结构对比。
- 同一个匿名教学案例的两个大限阶段对比。

对比不是 AI 自由解读。服务端使用版本化规则引擎逐项提取匿名事实，再将每个维度标记为“共同”“差异”或“资料不足”，因此结果可重复、可测试、可追溯。

## 2. 产品入口

- `/cases`：案例库顶部新增“命盘对比”入口。
- `/cases/[caseId]/study`：教学详情新增“加入命盘对比”。
- `/cases/compare`：选择对比方式、案例和大限，并查看最近对比。
- `/cases/compare/[id]`：查看保存后的逐维度结果与证据路径。

## 3. 两类对比

### 3.1 两个命盘

固定比较十个维度：

1. 命宫位置。
2. 身宫位置。
3. 五行局。
4. 出生时辰可信状态。
5. 命宫主星，空宫时使用匿名快照中已保存的借对宫星曜。
6. 命宫三方四正主星。
7. 空宫分布。
8. 本命四化落宫。
9. 确定性格局引擎识别结果。
10. 已确认匿名事件类别。

两个命盘必须来自不同案例。同一案例不允许伪装成双命盘比较，应使用大限对比。

### 3.2 同案例两个大限

固定比较七个维度：

1. 大限年龄范围。
2. 大限所在宫位。
3. 大限宫干。
4. 大限四化。
5. 大限宫中的本命星曜。
6. 大限宫与命宫、身宫的结构关系。
7. 与大限年龄范围相交的匿名事件类别。

事件只按脱敏后的十岁年龄段作粗粒度匹配，不把事件与大限建立因果关系。

## 4. 三态比较语义

| 状态 | 判定方式 | 页面含义 |
| --- | --- | --- |
| 共同 | 标量一致，或归一化后的集合完全一致 | 两侧匿名记录相同 |
| 差异 | 两侧均有资料，但标量或集合不同 | 显示共同项和两侧独有项 |
| 资料不足 | 至少一侧缺少该维度需要的数据 | 不强行得出相同或不同 |

“共同”只描述结构相同，不代表人生结果相同；“差异”也不是优劣或关系好坏判断。

## 5. 数据与缓存

SQLite v20 新增 `case_comparisons`：

- 保存模式、两侧案例、可选大限键、引擎版本和结构化结果。
- `comparison_key` 对同一模式、案例、阶段和引擎版本建立唯一约束。
- 重复创建同一组合会刷新原记录，不会持续生成重复数据。
- 保存两侧案例的 `updated_at`；读取详情时发现来源案例已变化，会自动重新执行规则引擎。
- 删除任一来源案例时，通过外键级联删除关联对比。

结果引擎版本为 `case-comparison-v1`。规则升级后可通过版本变化触发重算。

## 6. 授权与隐私边界

创建、列表和详情读取都要求两侧案例满足：

- 案例状态为 `reviewed`。
- `teaching` 授权仍为 `active`。

撤销任一来源案例的教学授权后，相关结果立即从列表隐藏，详情接口同时拒绝访问。保存的结果仅含匿名案例编号、匿名标题、匿名命盘快照的派生事实、规则格局和匿名事件类别，不读取或保存：

- 来源会话编号。
- 姓名、精确出生日期、地点或联系方式。
- 原始聊天正文。
- 原始事件标题、描述和具体地址。

对比标题由匿名案例标题和阶段标签自动生成，不接受自由文本输入，避免额外引入个人信息。

## 7. 接口

- `GET /api/case-comparisons`：列出仍满足授权条件的对比。
- `POST /api/case-comparisons`：创建或刷新确定性对比。
- `GET /api/case-comparisons/[id]`：读取结果，必要时自动重算。
- `PATCH /api/case-comparisons/[id]`：归档或恢复对比。

## 8. 自动化测试

`npm run test:case-comparisons` 使用独立临时 SQLite 验证：

- SQLite v20 迁移。
- 两命盘十维对比和同案例大限七维对比。
- 三态计数覆盖全部比较维度。
- 重复组合复用已有记录。
- 案例更新后结果自动刷新。
- 结果不包含来源会话编号和隐私字段。
- 授权撤销立即阻止详情访问并从列表隐藏。
- 对比归档、恢复和案例删除后的级联清理。

## 9. 已知边界

1. 本阶段实现大限对比，尚未实现同案例两个流年或两个具体年份的逐层对比。
2. 对比结果是确定性结构事实，不生成综合吉凶、关系判断或普遍因果结论。
3. 事件与大限的匹配受匿名年龄段精度限制，页面会持续展示此限制。
4. 当前面向本地单人部署，不包含多人协作、公开案例市场或云端同步。
