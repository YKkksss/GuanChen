# 梅花占类取用复核

开发及验收日期：2026-10-17，北京时间（UTC+08:00）。

## 本轮功能

新建梅花占问增加“本次占类”，明确选择未指定、求谋、求财或出行。默认未指定，问题、标题、备注及聊天中出现某个占类字样都不能替代选择。改变选择沿用起卦条件更新流程：撤回原预览并中止尚在返回的预览请求；保存期间锁定输入。

新增占类角色、体用条件、互变并列、规则来源四个视图，支持方向键及 Home/End 切换。角色保留本卦固定体、本用、下互、上互及变用五个位置，即使卦名相同也不合并。来源面板可展开原典链接、边界与保存版本；内部证据编号收在详情中。

明确占类只赋予本体与本用主客角色：求谋的用为所谋事项，求财的用为所问财物，出行的用为所行之应。出行占不等同行人占。相同生克方向使用各占类自己的说明，例如求谋的体克用还保留推进迟缓的传统侧重点，求财侧重主方制财，出行侧重主方与行程应事的制约关系，不能共用“有利／成功”标签。

本用条件采用所选占类条目；上下互、变用只采用通用体用关系，分别与原固定体比较，不把本用的占类古断机械套给每个辅助位置，也不另指派现实人物、财物或行程阶段。每条保留固定体和对照卦的五行、原关系、各自季节、待核条件和来源。与本用相反的辅助关系仍保留；同源结构、共享爻及重复卦不计票、抵消或合成评分。

未提供明确时刻时，两侧季节均为未定位。选择占类不改变起卦计算、互卦口径、固定体、取象目录或原有应期参考卦；没有新增得财日期、行止类象、交通方式、外应采集、现实对象识别或完整效力判断。

## 原典和适用边界

本轮核对[《梅花易数》卷二](https://zh.wikisource.org/wiki/梅花易數/卷二)的[求谋占第八](https://zh.wikisource.org/wiki/梅花易數/卷二#求謀占第八)、[求财占第十](https://zh.wikisource.org/wiki/梅花易數/卷二#求財占第十)、[出行占第十二](https://zh.wikisource.org/wiki/梅花易數/卷二#出行占第十二)及[体用总诀](https://zh.wikisource.org/wiki/梅花易數/卷二#體用總訣)。只将传统角色和关系侧重点改写为可复核条件，没有把确定性古断转换成真实事件结论。

本版没有覆盖书中全部占类或流派。求财条件不作金额、投资品种、买卖时点或收益判断；出行条件不作路线、安全、事故或是否应出行的判断；求谋条件不宣告项目成功或失败。季节旺衰、结构生克、关系实际效力与现实事实分别处理。

## 计算、保存和版本

- 新增 `lib/meihua/scenario-types.ts` 与 `scenario-engine.ts`，由 `analyzeMeihuaReading` 在新计算时建立 `reading.scenario`。`none` 和省略规范为同一输入，非法值、原型键、非字符串拒绝；不增加独立可伪造的客户端结果入口。
- 新 reading 为 `meihua-reading-v3-explicit-scenarios`；保留季节 v1、取象 v2 的完整标识。起卦基础版本不变，数据库保持 v56，无迁移。
- 保存仍由服务端根据原始输入计算；占类及规则随完整结果进入指纹，同条件复用、更换占类另存。读取只解析已保存 JSON，旧三代不补算或改写。
- 新问答为 `meihua-chat-v4-explicit-scenarios`。新版选定占类提供角色、体用条件、互变并列三条快捷草稿，按钮不自动发送；未指定及旧记录保留原快捷。
- 提示按实际保存能力分四层：明确占类 v4、取象 v3、季节 v2、基础 v1。占类版本、键、状态及输入选择须一致；不支持的层只从模型消息及可引用集合撤回，继续使用其余已支持层，不改原记录。
- 新版回复至少引用一条占类依据及一条取象依据，未指定可引用占类口径依据。旧三代继续各自引用边界；停止、失败、重试和请求幂等沿用原账号作用域。

## 验收

核心专项覆盖 64 卦 × 6 动爻 × 2 互卦口径 × 4 占类的 3,072 个真实组合；逐位置核对固定体、源盘原爻、五行关系、场景角色、本用与辅助范围及季节。另覆盖四种起卦法、默认规范化、非法输入、四代快照、未知或矛盾占类撤回、引用、保存重开、备份恢复、账号与同源保护。

新增占类专项 106,991 项、旧取象专项 74,064 项、季节专项 6,221 项、基础专项 2,456 项均首跑通过。真实 HTTP 105 项、网页 47 项和四视图在 320／390／768／1280 四宽度下的 16 组布局检查通过。独立复查修正了变用方向句拼接重复的问题，修复后重新检查方向句和布局；最终生产构建通过，生产启动后的 20 项只读检查通过。

测试只使用独立临时账号和数据库，AI 请求只发往本机模拟供应商。共享开发验收服务累计 9 次模拟请求（HTTP 8 次、网页 1 次），生产只读验收 0 次；新增专项自身的 7 次模拟独立记录，不与共享会话或全量中的再次运行混加。没有调用真实模型，不将其视为真实模型质量或实际手机验收；未运行 axe，未观察到应用控制台错误，保留了一条品牌 SVG 预加载未及时使用的开发警告。

网页验收原 Tabbit 连接未注册、CUA 没有可用浏览器，回退 Playwright 的本地临时页完成；结束后恢复视口、关闭该临时页，保留原页。两张最终磁盘截图均已实际查看。临时 QA 服务已关闭，日常 30001 服务保留，登录页 HTTP 200；Next 自动加入的临时类型路径恢复为日常配置。

唯一一次全项目回归 102/102 组通过，无失败或重跑；原始汇总及 102 份日志保留，证据复制完整结果。恢复日常配置后最终 `tsc --noEmit` 通过。本轮未提交或推送远程。

## 下一阶段计划

建议下一项为“八字原局深化：人元司令与月令分日复核”，具体范围如下：

1. 先核对十二月司令分日的原典、表格与流派差异，确定能公开追溯的一个明确口径；分歧不能暗中合并。
2. 按精确交节和明确的北京时间定位月内位置，将月支藏干、人元司令及现有调候分支分别展示；未知时辰或跨界只能给候选／待核。
3. 将司令位置与已有表干、藏根、月令格局候选逐条连接，说明采用与未采用条件，不凭单一标签裁定最终强弱、喜忌或格局成败。
4. 将明确口径及来源随新论命快照保存，接入报告依据与连续问答；旧报告不补写新规则。
5. 验收十二月与交节边界、长短月和未知时辰、旧新版本、引用、保存重开、账号隔离及桌面／窄屏布局。

本轮未实施下一阶段，不把上述计划计入已完成范围。梅花其余占类、后天端法、外应、完整作用效力和精确应期继续分别保留待核。
