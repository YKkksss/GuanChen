# 移动端网页版适配第二阶段实施记录

## 1. 阶段目标

第一阶段解决“可以使用”，第二阶段重点解决手机和平板上的拥挤感、阅读密度和操作入口过多问题。本阶段继续保留现有业务路由、表单字段、命盘算法和数据结构，只调整响应式布局与交互呈现。

## 2. 统一空间规范

| 设备范围 | 页面外边距 | 主要布局策略 |
| --- | --- | --- |
| 0-359 像素 | 14 像素 | 极窄屏保留必要操作，按钮隐藏辅助文字 |
| 360-600 像素 | 18-20 像素 | 单栏阅读、抽屉导航、卡片内部留白 |
| 601-820 像素 | 28 像素 | 平板竖屏单栏、较宽内容卡片 |
| 821-1080 像素 | 最大 28 像素 | 平板横屏聚焦视图，不强行并排命盘与对话 |
| 1081 像素以上 | 保持桌面规则 | 历史、命盘、AI 解读三栏工作台 |

统一规则：

- 页面内容不贴屏幕边缘。
- 提示条从全宽横条改为有边界的内容卡片。
- 手机触控按钮保持至少 44 像素高度。
- 手机与平板优先展示一个主要任务，避免多个工作区同时争抢宽度。
- 独立滚动区域只在命盘、聊天记录等确有需要的位置使用。

## 3. 命盘工作台重构

### 3.1 顶栏

- 1080 像素及以下只保留品牌、“历史”和“功能”三个主要区域。
- 学习中心、学习模式、专题报告、人生事件、年度分析和校正时辰收进右侧功能抽屉。
- 功能抽屉打开时锁定背景滚动，支持遮罩关闭和 Escape 键关闭。
- 历史抽屉与功能抽屉互斥，避免左右面板同时覆盖页面。

### 3.2 命盘与 AI 解读

- 1080 像素及以下统一使用“查看命盘 / AI 解读”聚焦切换。
- 平板横屏不再强行将命盘和 AI 对话压成窄双栏。
- 命盘、聊天各自占用完整内容宽度，减少文字压缩和输入区拥挤。

### 3.3 十二宫阅读模式

手机命盘提供两种显示方式：

- “总览”：完整显示十二宫方盘，用于观察整体结构。
- “放大”：默认模式，保持宫位文字可读，并在命盘卡片内部左右滑动。

横向滚动只发生在命盘阅读区域，页面本身不会产生横向溢出。平板宽度足够时直接展示完整方盘，不显示额外切换工具。

## 4. 通用功能页优化

- 东方书院公共顶栏在手机端使用 18-20 像素安全边距。
- 八字、报告、时间轴、案例、学习和数据管理等标准页面统一使用 20 像素手机边距与 28 像素平板边距。
- 八字和其他模块化页面的页头、表单与结果区使用相同的左右基线。
- 命理提示条在手机端增加圆角、完整边框和独立外边距，减少贴边压迫感。

## 5. 首页优化

- 手机页头左右边距由 14 像素提升到 18 像素。
- 首屏文字区域左右留白提升到 26 像素。
- 功能说明项内部留白提升到 26 像素。
- 后续内容区统一使用 20 像素页面边距。

## 6. 验收视口

本阶段使用以下视口实际检查：

- 手机：390 × 844。
- 平板竖屏：768 × 1024。
- 平板横屏：1024 × 768。

验收重点：

1. 页面根节点没有横向溢出。
2. 手机页面左右留白一致。
3. 手机命盘默认文字可读，横向滚动限制在命盘卡片内。
4. 平板命盘完整显示，不与 AI 区域互相挤压。
5. 历史与功能抽屉能够独立打开和关闭。
6. 抽屉打开时背景不能继续滚动。
7. 首页和通用功能页保持一致的移动端视觉节奏。
