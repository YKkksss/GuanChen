# 奇门深化：日时干与宫门星仪条件复核

后续阶段见 [奇门占类取用与条件对照（2026-10-16）](./QIMEN_SCENARIOS_IMPLEMENTATION.md)。本文保留上一版复核的能力范围和历史验收记录。

本轮承接六爻条件复核，交付既定深化顺序的第四项，入口 `/qimen`。数据库保持v56，在原盘面JSON中增加可选深化快照，不新增表或迁移。本阶段不进入动态紫微八字合参，不推送或合并远程。

## 使用流程与能力

新建占问可明确选择日干、时干、日时干对照、开门、生门、天辅星或手选宫位作为参考，也可暂不指定、先逐宫核对。模板只定位所选符号，不从自由文本推测人事身份，也不把日干、时干固定成所有占类中的本人和事情。

日干甲和时干甲分别按各自干支柱所属旬遁六仪。保留地盘原宫、地盘寄宫与天盘随星落宫；原中五不被寄宫覆盖。日时干对照只比较已定位天盘宫的五行，不直接判成败。点击参考落宫可联动九宫，原方向键、Home／End导航继续可用。

选中宫位的深化面板展示：

- 宫和八门的普通五行月令参考，与九星专门口诀分开展示。
- 门克宫的门迫，以及宫克门的宫制门；二者不混用，也不由月令状态抵消。
- 本宫各天盘干与有效地盘干逐组加临。坤二地盘包含本宫干及原中五寄干；天盘原中五仪仍随天禽天芮转动。中五只保留原地盘参照，不另布活动星门神或加临格局。
- 六仪击刑、表列三奇入墓及四种明确干组合的位置核对。多地盘干不会使同一天盘干的击刑、入墓重复计数；丁墓口径的异文单独标记。
- 星伏吟、门伏吟、星反吟、门反吟分别核对，单层成立不概称整个盘星门都成立。
- 明确参考宫位所含地支、时旬空和逢冲等待核条件，不生成确定公历应验日或行动方位保证。中宫无固定支，不补造对应地支。

所有关系、月令和格局不合成吉凶分数。时旬空只标对应支，不把部分支空写成全宫或所有符号都无用。

## 固定规则与来源

深化规则版本 `qimen-reading-v1-focus-palace-door-star`，基础排盘仍使用原时家转盘拆补、阴阳俱寄坤版本。

主要来源：[《奇门遁甲统宗》卷一“四十格”“九星旺相”“迫”](https://zh.wikisource.org/wiki/奇門遁甲統宗)，并以 [《奇门遁甲元灵经》](https://zh.wikisource.org/wiki/奇門遁甲元靈經) 核对六甲遁仪、寄宫及不同占类的取用差异。不继承原典确定性断语。

| 规则 | 本版口径 |
| --- | --- |
| 宫、门普通五行月令 | 同月旺、月生相、生月休、克月囚、月克死；辰戌丑未按土月，不冒充八节门旺、长生或人元司令 |
| 九星专门口诀 | 星生月旺、同类相、月生星死、月克星囚、星克月废；不套用普通五行状态，死等为传统术语 |
| 八门五行 | 休水、生死土、伤杜木、景火、惊开金；门迫按五行关系计算，包含木门克坤二、艮八土宫，不沿用原典表的个别漏项 |
| 六仪击刑位置 | 天盘戊震三、己坤二、庚艮八、辛离九、壬巽四、癸巽四；不由地盘干自行触发 |
| 三奇入墓位置 | 固定四十格表的乙坤二、丙乾六、丁艮八；同书歌诀另见丙丁归乾的异文，丁的提示保留，不合称唯一通则 |
| 明确干组合 | 天盘乙加地盘辛：龙逃走；天盘辛加地盘乙：虎猖狂；天盘癸加地盘丁：蛇夭矫；天盘丁加地盘癸：雀投江。只标加临结构，不继承确定性吉凶 |
| 星门伏反吟 | 分别以外八宫星、门来源同宫或对宫计算。天禽按寄坤随芮，不拿中五强算对宫 |

没有把任意戊加丙冒充原典“甲值符加丙”的龙返首。本阶段未包含完整十干克应、暗干、驿马、八节门旺、长生十二状态、完整格局效力、全部占类自动取用和精确应期；置闰、飞盘与其他寄宫流派仍待后续单独校核。

## 保存、问答与安全

新盘由服务端从原始时间、局数口径和明确参考对象重算，客户端账号或伪造复核不能覆盖。新增模板、宫位参数采用严格校验：未知及继承属性名拒绝，手选宫必须是1至9整数，其他模板不能混入手选宫位。改变条件会清除旧预览并取消旧请求；保存时锁定表单。

深化结果及 `reading:` 依据与原占问固定保存在 `result_json`。旧记录读取不补算新复核、不增加新依据、不重写旧回复，页面明确标记未含深化快照。备份、恢复、账号库隔离和私有不缓存响应沿用原有安全边界。

问答版本 `qimen-chat-v2-conditional-reading`：新盘使用已计算条件，旧盘保持原能力边界。模型不能把入墓异文、旬空和单层伏反吟改成确定成败，也不能补造未计算规则；回复须引用实际存在的1至8条依据。原停止、失败重试、幂等、分页及宫位追问追加草稿逻辑继续保留。
