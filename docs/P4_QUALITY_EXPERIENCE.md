# P4 质量与体验验收

日期：2026-10-18。范围：本地/局域网真实浏览器体验；真机与真实模型不属于本轮自动验收。

## 1. 浏览器 E2E

新增 `scripts/qa-web-e2e.ts`，命令：

```bash
npm run qa:web-e2e
```

内容：

- 启动隔离的 `next start`（127.0.0.1:30004）+ 临时账号数据。
- 使用本机 Chrome/Edge（Playwright Core，无额外浏览器下载）。
- 通过真实注册表单建立账号。
- 通过真实 API 创建一张合成命盘。
- 覆盖页面：首页、命盘工作台、八字、梅花、六爻、奇门、择日、合参、历史档案、账号设置、数据保险箱。
- 宽度：1280 / 768 / 390 / 320。
- 检查：HTTP 状态、横向溢出、控制台错误、页面异常。
- axe-core（WCAG 2A/2AA）在 390/1280 下检查首页、命盘、八字、账号设置、数据保险箱。

结果：

- **46 项页面/宽度检查全部通过**。
- **0 个横向溢出**。
- **0 个控制台错误、0 个页面异常**。
- **0 个 critical/serious axe 违规**。

首次运行 axe 在命盘页报 `color-contrast`，原因是 Framer Motion 入场动画尚未结束，axe 读取到透明度中间态。已在检查前等待 1.2 秒，复跑后 0 违规；这不是放宽规则，而是避免把动画中间帧当成静态样式。

## 3. 已验证的体验点

- 注册表单、登录跳转、账号菜单在真实 Chrome 中可用。
- 侧栏 11 个命理入口、档案、设置页在 320 宽度下无横向溢出。
- 命盘工作台桌面布局与右侧 AI 区域正常渲染。
- 无控制台异常，说明客户端水合与路由没有明显错误。

## 4. 尚未完成

- iOS/Android 真机验收；当前只有桌面 Chrome 的视口模拟。
- 完整聊天流式、报告生成、PDF 下载、备份恢复的浏览器端到端（这些在各自专项/HTTP 测试中覆盖，未全部合并到浏览器脚本）。
- 每个模块的空状态、错误状态、加载状态逐项人工巡检；当前只验证页面可打开与无溢出。
- 真实供应商输出质量与延迟；属于 P5 可选验收。

## 5. 结论

本地浏览器主链路已可用，四宽度无横向溢出，axe 无阻断问题。P4 可以标为“本地浏览器验收完成、真机待用户设备确认”，不宣称真机已通过。
