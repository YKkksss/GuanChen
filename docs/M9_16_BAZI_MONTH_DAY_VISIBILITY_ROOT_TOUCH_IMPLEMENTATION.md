# M9-16 八字流月流日显隐、透根与藏干触达条件审计实施说明

## 1. 阶段结论

M9-16 在 M9-15 指定流日五层关系证据之上，补齐了流月、流日参与的三组条件证据：

- 同干与同十神的显隐重复簇；
- 藏干对表层的完全同干匹配，以及表层对藏干的严格同干根、同五行支持；
- 藏干被完全同干动态表层、同支重复或明确地支关系触达的入口。

系统继续按流日内部精确片段独立审计。每一项输出都必须有流月或流日参与，避免重复展示 M9-9 至 M9-11 已经完成的纯原局、纯岁运证据。

本阶段只回答“哪些位置同见、哪些条件匹配、哪些入口触达”，不回答力量是否增强、藏干是否发动、格局是否改变、时间吉凶或具体事件。

## 2. 为什么不能只把 M9-9 至 M9-11 的年度结果直接搬过来

M9-9 至 M9-11 的审计粒度是原局、大运、流年，不能直接覆盖流月、流日：

1. 流月按节界切换，不按公历月初切换；
2. 流日可能在当天中途跨越节界或交运时刻；
3. 同一天前后片段的大运、流月可能不同；
4. 如果不限定动态参与层，会把大量与当天无关的旧证据重复输出；
5. 显隐、透根与触达是三种不同条件，不能混成一个“力量变化”结论。

因此 M9-16 以 M9-15 已版本化的精确片段为唯一入口，在每个片段内重新组合实际存在的位置，再复用上游规则。

## 3. 上游规则复用

### 3.1 M9-9：显隐重复

复用内容：

- 表层天干、藏干和日主参照保持独立位置；
- 同干簇与同十神簇分别聚类；
- 跨层表层同干、表层与藏干同见、跨层藏干同见分别标记；
- 天干表层关系可以回指 M9-15 的关系证据；
- 位置数量不折算力量。

M9-16 新增的过滤条件是：每个重复簇至少包含一个 `month` 或 `day` 位置。

### 3.2 M9-10：透干与通根条件

复用内容：

- 藏干与表层天干必须完全同干，才记为透出条件匹配；
- 原局月支藏干继续单列为月令藏干；
- 表层天干与藏干完全同干，才记为严格同干根候选；
- 同五行但不同干只能记为同五行支持参照；
- 表层与完全同干藏干位于同一节点时，单列坐支同干位置；
- 所有候选均不裁决真假、强弱和有效性。

M9-16 只保留候选自身或其匹配位置包含流月、流日的记录。

### 3.3 M9-11：藏干触达入口

复用三类入口：

1. 同片段出现完全同干的动态表层；
2. 不同节点出现相同地支；
3. 藏干所在支参与明确冲、合、刑、害等关系证据。

关系入口继续回指 M9-15 的关系证据和条件状态。即使多个入口并见，也只标记“多类触达条件”，不宣告藏干已经引动或发动。

## 4. 公共片段能力改造

为了避免建立第二套规则，本阶段把 M9-9、M9-10、M9-11 的核心计算整理为可复用的精确片段函数：

- M9-9 可以接收任意动态层集合，并指定重复簇必须包含哪些关注层；
- M9-10 可以接收任意显隐位置集合，并指定透出、根气候选必须由哪些关注层参与；
- M9-11 可以接收任意片段关系和条件记录，并过滤只由关注层产生的触达候选。

原有年度审计继续以 `annual`、`luck_cycle` 为关注层，行为保持不变；M9-16 使用 `month`、`day` 为关注层。专项回归覆盖了两种调用方式。

## 5. 精确片段与证据隔离

M9-16 完全继承 M9-15 的片段起止：

```text
流日片段
  ├─ 原局显隐位置
  ├─ 当时大运显隐位置（未交运时不存在）
  ├─ 当时流年显隐位置
  ├─ 当时流月显隐位置
  └─ 当时流日显隐位置
```

如果同一天 `06:51:00` 交入新大运，前一片段不能包含新大运位置，后一片段才允许形成包含新大运的重复簇、透根候选和藏干触达入口。

所有片段使用前闭后开的时间区间。前后片段的证据不能累计为数量、力量或最终结论。

## 6. 输出结构

每个精确片段包含三组审计结果。

### 6.1 显隐重复审计

- 同干重复簇；
- 同十神重复簇；
- 每个位置的层级、显隐状态、天干和十神；
- 表层天干关系证据连接；
- 表层与藏干同见等模式标签。

同干簇允许包含日主参照；同十神簇不把日主自身误计为比肩。

### 6.2 透出与根气条件审计

- 完全同干表层匹配或缺失；
- 月令藏干与一般藏干区分；
- 严格同干根候选；
- 仅同五行支持；
- 坐支同干位置；
- 上游同干簇回指。

“严格同干根候选”是结构名称，不等于强根、真根、得根有力。

### 6.3 藏干触达条件审计

- 每个被审计藏干的位置与十神；
- 三类入口分别匹配或缺失；
- 单类入口和多类入口并见；
- 关系入口对应的证据 ID 与条件状态；
- 候选是否属于月令藏干。

“触达”只说明藏干所在位置与已开放入口产生了结构联系，不等于藏干实际发动。

## 7. 数据模型与按日缓存

SQLite 升级到 v38，新增 `bazi_month_day_visibility_versions`：

- `chart_version_id`：绑定不可变命盘版本；
- `month_day_relation_version_id`：绑定 M9-15 五层关系证据版本；
- `target_date`：当前条件快照的有效日期；
- 方法版本、引擎版本与两个上游指纹；
- 所有片段的重复簇、透根候选和触达候选 JSON；
- M9-16 结果指纹与创建、更新时间。

唯一键由命盘版本、M9-15 版本、目标日期、方法版本和引擎版本组成。相同输入重复请求复用已有结果；上游指纹或方法版本变化后可以生成新版本。

`bazi_conversations.month_day_visibility_version_id` 绑定对话默认日期的 M9-16 版本。旧会话打开时会幂等补齐字段和当前提示词版本。

## 8. API

新增：

- `POST /api/bazi/charts/:id/month-day-visibility`：按 `targetDate` 生成或复用 M9-16 版本；
- `GET /api/bazi/charts/:id/month-day-visibility?date=2030-12-12`：读取指定日期的最新结果，并返回已缓存版本列表。

服务端先确保 M9-15 五层关系版本存在，再生成 M9-16 结果。日期校验、流年归属和节界边界继续服从 M9-14、M9-15，不在本阶段建立第二套日期算法。

## 9. 工作台交互

八字工作台在 M9-15 五层关系面板后新增 M9-16 面板：

- 选择流日后同步确定性计算；
- 顶部展示同干簇、透出匹配和藏干触达数量；
- 每个精确片段单独展示，不合并跨运前后证据；
- 显隐重复默认展开；
- 透出与根气、藏干触达使用可折叠区域，控制长页面高度；
- 复用已经验证的同干簇、透出候选、根气候选和触达候选卡片；
- 已保存命盘在后台按日期持久化。

## 10. AI 上下文与输出边界

提示词升级为 `bazi-chat-month-day-visibility-v15`。

用户问题包含明确日期，或询问“今天/今日”时，上下文按顺序绑定：

1. M9-14 精确流月流日时间事实；
2. M9-15 五层关系与十神角色；
3. M9-16 显隐、透根与藏干触达条件。

上下文清单新增：

- `monthDayVisibilityVersionId`；
- `monthDayVisibilityFingerprint`；
- `monthDayVisibilityTargetDate`。

新增允许能力：

- `month_day_visibility_root_touch_audit`

新增禁止能力：

- `month_day_visibility_effect_verdict`

输出守卫会拦截把流月流日的透出、通根、同干、同支或触达直接解释为强根、真根、发动、冲开、变强、变弱、吉凶或事件应验的回答。

## 11. 降级规则

- 时辰未知：保留年、月、日柱及动态层，所有时柱显隐位置和相关条件不参与审计；
- 非支持时区：M9-15 没有精确流日片段时，M9-16 返回 `sequence_only_unavailable`，不伪造条件；
- 未交首运：片段中没有大运位置，不创建含大运的重复或触达证据；
- 日期越界：沿用 M9-15 的明确错误，不静默替换日期；
- 没有候选：保留空状态，不用自然语言补写不存在的证据。

## 12. 测试覆盖

专项测试 `test:bazi-month-day-visibility` 覆盖：

- 方法契约和禁止结论；
- 同一交运日的前后双片段隔离；
- 每个重复簇必须包含流月或流日位置；
- 每个透出、根气候选必须由流月或流日参与；
- 每个藏干候选自身或触达入口必须包含流月或流日；
- 交运后的重复簇才允许包含新大运位置；
- 严格同干根与同五行支持分离；
- 单类和多类藏干触达入口；
- 未知时辰与非支持时区安全降级；
- SQLite v38 迁移、版本指纹和同日幂等复用；
- API、对话默认绑定和问题日期动态路由；
- 流月流日显隐作用越权输出守卫。

同时回归 M9-9、M9-10、M9-11 和 M9-15，验证公共片段能力没有改变旧结果。

## 13. 当前仍不能回答的问题

M9-16 完成后仍不能自动回答：

- 同干、同十神重复是否使某五行变强；
- 某个严格同干根候选是否为强根、真根或有力；
- 藏干被触达后是否已经发动；
- 冲合刑害是否冲开、合住、解冲或完成合化；
- 流月流日加入后日主最终增强或减弱；
- 格局在某日是否成格、破格或完成救应；
- 某日吉凶和事业、感情、健康、财务等具体事件。

## 14. 下一阶段：M9-17

下一阶段建议开发“流月流日旺衰综合证据矩阵”。它将在同一精确片段内复用 M9-12 的静态基线、岁运表层方向、月令触达和根气条件分层，把流月、流日新增的表层十神方向与 M9-16 条件上下文并列展示。

M9-17 仍只输出生扶、泄耗制、同向、异向、并见和条件来源，不计算最终旺衰分数，不宣告日主变强或变弱，也不预测吉凶事件。
