# 八字人元司令与月令分日复核

开发及验收日期：2026-10-17，北京时间 UTC+08:00。

## 本轮功能

八字论命总览增加独立的“人元司令与月令分日复核”，含分日定位、司令与透藏、月令对照、规则来源四个视图。当前只采用一个明确命名的来源口径：“三命通会主段 · 三十日定长观察”。它是独立的原典分日观察层，不替换保存月柱、本气藏干、现有旺衰标签、格局候选或《穷通宝鉴》调候月内分支。

可以查看实际节令月的精确交节起止、观察时刻或整日区间、已过天时分秒、原文分段及本次候选。原表所有涉及分段保留，可展开未命中的段；长节月尾段另列。四视图支持方向键及 Home/End 切换，细节和内部依据编号默认收起。

有明确天干时，分别列出相对已保存日主的十神、非日干的表层同干、日干同干参照、严格同干藏根、同五行其他藏干及同源格局候选。只连接实际存在的位置，不因为原典司事名称出现就新增一个藏干或根。出生时辰未知时，新层司事段与月藏对照的十神均撤回为 null，原盘保存的试排资料不改；未见位置不能视为全盘缺失。

## 原典与项目计算约定

定向核对[《三命通会》卷二·论人元司事](https://zh.wikisource.org/wiki/三命通會/卷二#論人元司事)和[四库本同章](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷02#論人元司事)。主段与后列“再考玉井”不是同一套表，同章还保留醉醒子对机械限日的不同意见。本版不将不同表揉成一张，也不称为唯一古法。

主段来源表如下；天数及次序按原文保留，不用现代通用藏干表校改：

| 寅 | 艮土5、丙火5、甲木20 |
| 卯 | 甲木7、乙木23 |
| 辰 | 乙木7、壬水5、戊土18 |
| 巳 | 戊土7、庚金5、丙火18 |
| 午 | 丙火7、丁火23 |
| 未 | 丁火7、甲木5、已土18 |
| 申 | 坤土5、壬水5、庚金20 |

艮土、坤土不直接改为戊或己；“已土”在四库转录作“巳土”，本轮保留原字并将具体天干设为待核。辰壬、未甲、戌丙、丑庚与常用藏干表不同，两者并列；不能把原表中的干补进已保存命盘。

为使分日可复查，本项目明确约定：从十二节的精确时刻起，每满 86400 秒计一日，使用左闭右开区间。这是工程观察口径，不宣称原典规定了现代秒级换算。源表每月合计三十日；实际节令月较短时在下一节截断，较长时超过三十日的部分为未覆盖尾段。不按月长比例伸缩，不延续最后一干，也不以公历某日或午夜替代原交节瞬间。

## 时间边界

- 只定位已保存且与 UTC+08:00 一致的民用时，检查出生观察区间及相关节月两端的时钟；历史夏令时、回拨歧义、其他时区和真太阳时先撤回定位。真太阳时盘不把有效墙上时钟再次当北京时间。
- 保存的输入与有效民用时不一致，或保存月柱与原有效时刻的精确节令月不一致时，保留原盘、显示待核，不静默重排。
- 未知时辰观察整个民用出生日期。若整日仅落一段，可定位这个区间，但出生瞬间仍未知；跨分日或跨交节则保留全部相交段，可能涉及两个节令月；若同时跨未覆盖尾段，尾段条件也保留。不能挑中午试排所在段作为唯一司事。
- 分段边界秒归后一段，右端不含；整日恰在午夜结束时不把次日算入。晚子时换日口径不挪动司事节界。
- 未知时辰的日主和月藏十神可能受时刻影响，新层不输出全日唯一十神，也不将试排日主的格局关系升级为整日结论。

区间定位只说明当前来源口径下的分段观察，不代表已判得令有力、身强身弱、根深浅、格局成败、最终用神或喜忌；没有增加力量评分或事件断语。

## 保存与问答

主要代码为 `lib/bazi/month-command-{types,rules,engine,output}.ts`，在新 `BaziReadingFacts.monthCommandReview` 中保存版本、口径、观察区间、原表段、位置对照、来源和边界。

论命规则升至 `bazi-reading-v5-month-command-review`，报告提示为 `bazi-reading-report-v5-month-command`。完整 facts 进入原报告指纹；数据库保持 v56，无新增迁移。服务端从自己的已保存八字计算，客户端提交的伪造 facts、结果或账号字段不能覆盖它。

旧报告继续读取原 facts/content，新视图在 AI 解读区域只使用当前所选版本的 `active.facts.monthCommandReview`；缺失时明确原报告没有保存此层，不借用最新复核。报告能力按实际字段选择 v1 至 v5；未知司事版本或口径同步撤回该层及其依据，继续保留原有能力，原文不改。

新 v5 报告旺衰章节须引用 `strength:month-command:`，格局章节须引用 `pattern:month-command:`，未定位的记录同样引用保存边界。连续问答为 v22，询问司令、人元、分日或节气深浅时带入同一口径的简短事实；普通和降级上下文均接入，司事段放在长方法段之前，纯岁运问题不插入整份司事复核。

三条追问入口只建立或打开当前命盘会话并填入草稿，仍由用户确认发送，不自动调用 AI。旧聊天正文不改，新回复使用当前规则。输出检查保留明确否定和待核表达，拦截用司事定位直接宣告强弱、成格、唯一喜忌、校改原字或自动补满尾段的越权肯定。
