# M5-4 出生时辰校正候选比较工作台实施说明

## 1. 阶段目标

M5-4 将 M5-1 至 M5-3 已完成的候选命盘、人生事件事实和规则评分能力整合为可直接操作的产品工作台。

本阶段解决以下问题：

1. 使用者可以从首页或现有命盘进入出生时辰校正。
2. 使用者可以创建、恢复和继续处理校时任务。
3. 使用者可以录入关键人生事件并观察证据准备度。
4. 使用者可以查看候选排名、命宫、身宫、主星和相对证据指数。
5. 使用者可以逐事件比较所有候选，并展开查看具体规则依据。
6. 使用者可以选择两个候选查看命盘结构差异。
7. 使用者可以把某个候选设为当前工作命盘，同时保留全部历史。

## 2. 页面与入口

### 2.1 校时入口页

路由：`/rectification`

主要能力：

- 展示本地校时任务历史。
- 新建校时任务。
- 支持姓名、出生日期、性别、出生地、历史时区和经度。
- 支持出生证明、医院记录、户籍记录、家人口述等时间来源。
- 支持精确时间、大约时间、时间范围、大致时段和完全未知。
- 支持 2 至 13 个候选时段，早子和晚子分别处理。
- 接受 `conversationId` 查询参数，从现有单人命盘带入基础信息。

### 2.2 候选比较工作台

路由：`/rectification/[id]`

页面包含：

- 证据准备度和当前评估状态。
- 关键人生事件录入表单。
- 横向候选命盘列表。
- 两候选结构差异对照。
- 事件与候选证据矩阵。
- 规则命中展开详情。
- 当前工作命盘选定区。
- 历次选定记录。

首页顶部导航新增“校时”入口。单人命盘工作区工具栏新增“校正时辰”入口，并携带当前对话编号。

## 3. 事件证据矩阵

矩阵以人生事件为行、候选时段为列，单元格展示：

- 支持
- 弱支持
- 中性
- 冲突
- 证据不足
- 当前事件对该候选的调整后贡献

只有具有区分度且调整后贡献不为零的规则，才决定单元格主状态。所有候选共同命中的事实仍可在规则详情中查看，但矩阵主状态显示为“中性”，避免把不参与排序的共同事实误读为有效支持。

展开单元格可以查看规则名称、证据结果、调整后权重、命中宫位、事件年份和范围衰减等信息。页面明确说明“未命中保持中性，不自动视为反证”。

## 4. 候选差异

候选卡片展示：

- 时段名称和民用时间范围。
- 命宫地支与命宫主星。
- 身宫地支与身宫落宫。
- 相对证据指数和名次。
- 并列、重复命盘和当前工作命盘状态。

使用者可以同时勾选两个候选。差异区只展示不同项，包括命宫、身宫、五行局和十二宫宫名、主星差异。

桌面端采用三列对照；手机端采用“比较项 + 两个候选值”的双列结构，避免横向文字失去归属。

## 5. 工作命盘选定与审计

新增数据表：`rectification_selections`。

每次选定保存：

- 校时任务编号。
- 候选命盘编号。
- 依据的评估编号和评估版本。
- 选定时的排名、相对证据指数和置信度。
- 留一事件稳定状态。
- 是否确认限制说明。
- 人工选定说明。
- 选定时间。

接口：

- `GET /api/rectifications/[id]/selection`
- `POST /api/rectifications/[id]/selection`

安全约束：

1. 候选必须属于当前校时任务。
2. 重复命盘候选不能被单独选定，必须选择对应主候选。
3. 评估必须属于当前校时任务。
4. 事件证据变化后，旧评估不能用于新的选定。
5. 低证据、并列、未稳定或未达到推荐证据量时，必须确认限制说明。
6. 选定只更新当前选择，不删除候选、事件、规则命中、评估和旧选择。

## 6. 视觉与交互约束

- 继续使用项目现有墨金强调色和 CSS 变量双主题。
- 不引入第二套大型组件库。
- 所有原生下拉选项使用白底黑字，避免暗色模式白字白底。
- 提供加载骨架、空状态、错误状态和按钮忙碌状态。
- 候选列表与证据矩阵允许独立横向滚动。
- 桌面与手机均保留完整信息，不用隐藏规则依据来换取布局空间。
- 相对证据指数不使用概率文案，也不使用容易暗示完成度的进度条。

## 7. 自动化与浏览器验证

新增命令：`npm run test:rectification-workbench`。

自动化测试覆盖：

- 评估版本绑定。
- 限制确认。
- 任务选定状态更新。
- 证据变化后的旧评估失效保护。
- 选择历史持久化。
- SQLite 第 12 版迁移。

真实页面验证覆盖：

- 新建任务入口与空状态。
- 事件录入。
- 规则评估。
- 候选排序。
- 证据矩阵。
- 规则详情展开。
- 候选选定和历史恢复。
- 深色模式。
- 手机窄屏布局。

## 8. 下一阶段

M5-5 进入校时结论解释与报告：

1. 由系统先生成结构化结论事实包。
2. AI 只解释规则结果，不修改分数、排名和置信度。
3. 输出最佳候选、主要区分证据、冲突证据、并列或不稳定原因。
4. 保存报告版本和生成时使用的评估版本。
5. 支持从已选定候选创建新的单人命盘会话，原命盘和校时任务继续保留。
