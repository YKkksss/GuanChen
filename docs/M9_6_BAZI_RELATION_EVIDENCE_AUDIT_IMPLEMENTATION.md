# M9-6 原局—大运—流年作用关系证据审计实施说明

## 1. 阶段目标

M9-6 在确定性四柱、大运排期和立春流年时间轴之上，建立版本化的跨层干支关系证据清单。程序只回答：

- 哪些原局柱、大运和流年参与了关系；
- 命中了哪一条天干或地支规则；
- 关系发生在哪一个真实时间片段；
- 哪些后续条件尚未校验。

本阶段不回答合化是否成立、哪一方力量更大、关系带来什么吉凶或会发生什么事件。

## 2. 三层节点与时间片段

每个流年按照 M9-5 的实际时间片段分别建立节点：

```text
原局年、月、日、时柱
        +
当前片段对应的大运干支（若已交运）
        +
当前流年干支
```

若流年中途交运，则交运前、交运后独立审计，禁止把后半年的大运关系写入前半年的时间片段。出生时辰未知时，时柱节点完全省略，不补造关系。

## 3. 首版开放规则

### 3.1 天干

- 同类五行；
- 五行相生；
- 五行相克；
- 五合：甲己、乙庚、丙辛、丁壬、戊癸。

五合会保存传统目标五行，但结论固定为 `detected_not_transformed`。目标五行只是规则元数据，不表示已经合化。

### 3.2 地支二字关系

- 六合：子丑、寅亥、卯戌、辰酉、巳申、午未；
- 六冲：子午、丑未、寅申、卯酉、辰戌、巳亥；
- 六害：子未、丑午、寅巳、卯辰、申亥、酉戌；
- 子卯相刑；
- 辰、午、酉、亥跨层重见时记录自刑。

### 3.3 三字关系

- 三合：申子辰、亥卯未、寅午戌、巳酉丑；
- 三会：亥子丑、寅卯辰、巳午未、申酉戌；
- 三刑：寅巳申、丑戌未。

三字关系只有全部成员出现才记录。不能把两个成员称为完整三合、三会或三刑。

## 4. 审计范围

每条证据保存以下作用范围之一：

- `luck_to_natal`：大运—原局；
- `annual_to_natal`：流年—原局；
- `annual_to_luck`：流年—大运；
- `multi_layer`：原局、大运、流年共同组成完整关系。

参与节点保存：

- 原局／大运／流年层级；
- 原局具体柱位；
- 天干或地支字符及五行；
- 大运序号；
- 流年年份。

首版不重复列举纯原局内部的二字配对；原局内部结构继续由 M9-3 负责。三字结构若由原局成员和动态成员共同补齐，则作为跨层证据记录。

## 5. 证据而非结论

每条证据包含：

- 关系领域和类型；
- 人类可读标签；
- 全部参与节点；
- 命中规则编号；
- 传统目标五行（仅部分合关系）；
- `detected_only` 或 `detected_not_transformed` 状态；
- 明确的暂缓说明。

项目不生成：

- 关系总分、吉分或凶分；
- 合化成功、破合或解冲裁决；
- 对旺衰、格局和用神的自动改写；
- 事业、感情、财运、健康或具体事件结论。

## 6. SQLite v28

新增 `bazi_relation_audit_versions`：

- 绑定命盘、大运和流年时间轴三个上游版本；
- 保存三个上游指纹；
- 保存关系方法版本与引擎版本；
- 保存关系审计指纹和完整结果 JSON；
- 相同上游版本和方法版本自动复用。

`bazi_conversations` 新增 `relation_audit_version_id`。新会话自动绑定关系审计版本，旧会话读取时自动补齐，并升级到提示词版本 `bazi-chat-relation-evidence-v5`。

## 7. 接口与页面

新增接口：

```text
GET  /api/bazi/charts/:id/relation-audit
POST /api/bazi/charts/:id/relation-audit
```

排盘页新增关系审计面板，并与 M9-5 流年选择器共用同一个年份状态：

- 切换年份后，时间轴和关系证据同步更新；
- 跨运流年显示多个独立审计片段；
- 每条证据显示天干／地支、作用范围、参与节点和方法边界；
- 五合、六合、三合和三会使用“只检测、不判化”提示。

## 8. 对话上下文

上下文新增“权威八字干支关系证据快照”。系统从当前问题识别年份，只注入对应年份的全部真实片段和证据，不把九十年关系清单全部传给模型。

新增允许能力：

- `relation_evidence_audit`。

新增禁止能力：

- `transformation_verdict`；
- `strength_effect_verdict`。

输出守卫增加“越权宣告合化”检测。

## 9. 来源边界

- [《三命通会》卷二·论十干合](https://zh.wikisource.org/zh-hans/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83/%E5%8D%B7%E4%BA%8C)：用于五合配对；
- [《三命通会》卷二·论支元三合](https://zh.wikisource.org/zh-hans/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83/%E5%8D%B7%E4%BA%8C)：用于三合成员齐全边界；
- [《蠡海集》六合与六害条](https://zh.wikisource.org/zh-hans/%E8%A0%A1%E6%B5%B7%E9%9B%86_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29)：用于六合、六害配对；
- M9-5 流年时间轴：用于真实跨运片段。

古籍中的性格、灾福和事件断语不进入结构引擎。干支关系属于传统命理模型，不是现代科学因果关系。

## 10. 自动化验收

```bash
npm run test:bazi-relation-audit
```

覆盖：

- 方法集合和禁止边界；
- 年中交运前后独立审计；
- 天干五合及未判化状态；
- 六合、六冲、六害、子卯刑、自刑；
- 完整三合和完整三刑；
- 未知时辰和未校准时区降级；
- SQLite v28、版本去重和对话绑定；
- 按问题年份构建关系上下文；
- 合化越权输出守卫。
