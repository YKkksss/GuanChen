# 命盘聊天阅读体验优化实施记录

日期：2026-09-05（UTC+08:00）

开发基线：`dev` / `bf8aff6`

范围：用户追加的命盘右侧 AI 对话空间优化，完成后继续原计划 F13–F15。SQLite 仍为 v47。

## 1. 使用体验

- 内容区足够宽时，命盘与聊天默认按 55% / 45% 分配净宽；原聊天列最大宽度为 360px。
- 中间分隔条支持拖动，松手后将偏好比例保存在当前浏览器。方向键每次调整 2 个百分点，Home / End 调到边界，Enter、双击或标题栏重置按钮恢复默认。拖动中按 Escape 取消本次调整。
- 命盘至少保留 520px、聊天至少保留 420px，分隔条 16px。内容区小于 956px 时改用“查看命盘 / AI 解读”切换；屏幕重新变宽时恢复保存的偏好比例。
- 点击“专注对话”展开聊天，正文和输入区居中、最大宽度 820px；点击“退出专注”或按 Escape 返回。弹窗打开时优先处理弹窗。
- 页头、专题栏和提示区域更紧凑，正文使用 15px 字号与 1.85 行高。长对话独立滚动，输入区保持在工作区底部。
- 人生事件候选默认显示数量入口，展开后仍可核对、修改、确认保存或忽略。确认一条后继续显示剩余候选。
- 消息、草稿和生成状态由已有 ChatSession 维护，专注和学习视图切换保留同一聊天实例。读最新消息时跟随底部，主动上翻后暂停跟随；重新排版不会被误认成用户上翻。

## 2. 关键实现

| 文件 | 作用 |
|---|---|
| `components/ChartWorkspace.tsx`、同名 CSS 模块 | 分栏、专注按钮、容器查询、视口高度与命盘最小尺寸 |
| `lib/ui/chat-split.ts` | 偏好校验与两栏宽度约束 |
| `lib/ui/use-chat-split.ts` | 指针捕获、键盘调整、比例存储、ResizeObserver 与无障碍数值 |
| `components/InsightPanel.tsx` | 可选阅读控制栏，仅命盘页启用紧凑布局 |
| `components/LifeEventCandidateInbox.tsx`、同名 CSS 模块 | 可选折叠摘要，保留原候选核对流程 |
| `lib/ui/use-smart-chat-scroll.ts` | 容器尺寸变化后的底部跟随，兼容先加载后挂载的聊天节点；执行延迟滚动前再次检查跟随意图 |
| `scripts/test-chat-split.ts` | 存储边界、最小尺寸、窄屏与宽屏恢复测试 |

拖动只通过动画帧更新 CSS 自定义属性和分隔条 ARIA 属性，避免整个命盘与消息列表每帧重新渲染。局部样式继续沿用现有东方书院配色。

## 3. 验收

专项命令均通过：

```text
npm run test:chat-split
npm run test:chat-scroll
npm run test:chat-keyboard
npm run test:chat-generation
npm run test:event-candidates
npm run test:learning-open-practice
npm run test:workspace-navigation
npx tsc --noEmit
npm run build
```

生产构建通过，完成 71 个静态页面生成及所有动态路由编译。

浏览器使用临时 SQLite、合成出生资料、长回答、两条合成候选及本地模拟流式服务，无真实 AI 外呼。

| 验收场景 | 结果 |
|---|---|
| 1440 × 900 桌面 | 内容区宽 1188px，默认聊天宽 527.4px，命盘宽 644.6px，输入框底部 857px |
| 拖动与刷新 | 实际拖动后刷新恢复比例；边界保留 520px 命盘；键盘和重置可用 |
| 专注与草稿 | 正文最大宽 820px，进入与退出均保留草稿；Escape 可退出 |
| 390 × 844 手机 | 页面无横向溢出，输入框底部约 825px，聊天与命盘单栏切换 |
| 768 × 1024 平板专注 | 聊天宽 744px，输入框底部约 1005px |
| 1024 × 600 矮屏 / 320 × 640 小屏 | 无页面横向溢出，输入框分别在 577px / 621px 内；窄内容区提供视图切换 |
| 生成中切换 | 专注与学习模式往返不丢回答；停止后保留部分正文，模拟上游确认取消 |
| 事件候选 | 默认折叠，展开后核对保存成功，数量由 2 变为 1，剩余候选继续可处理 |
| 滚动 | 停在底部时切换专注仍在底部；上翻并停留旧消息后切换保留阅读位置 |
| 浏览器日志 | 最终检查未发现 error / warn |

手机结果来自桌面浏览器视口模拟；实体设备软键盘弹起尚未实机验收。
