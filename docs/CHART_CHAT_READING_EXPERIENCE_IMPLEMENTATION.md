## 1. 使用体验

本节和第 3 节记录第一轮交付；最新字号、内容宽度、输入区和设置行为以第 5 节为准。

- 内容区足够宽时，命盘与聊天默认按 55% / 45% 分配净宽；原聊天列最大宽度为 360px。
- 中间分隔条支持拖动，松手后将偏好比例保存在当前浏览器。方向键每次调整 2 个百分点，Home / End 调到边界，Enter、双击或标题栏重置按钮恢复默认。拖动中按 Escape 取消本次调整。
- 命盘至少保留 520px、聊天至少保留 420px，分隔条 16px。内容区小于 956px 时改用“查看命盘 / AI 解读”切换；屏幕重新变宽时恢复保存的偏好比例。
- 点击“专注对话”展开聊天，正文和输入区居中、最大宽度 820px；点击“退出专注”或按 Escape 返回。弹窗打开时优先处理弹窗。
- 页头、专题栏和提示区域更紧凑，正文使用 15px 字号与 1.85 行高。长对话独立滚动，输入区保持在工作区底部。
- 人生事件候选默认显示数量入口，展开后仍可核对、修改、确认保存或忽略。确认一条后继续显示剩余候选。
- 消息、草稿和生成状态由已有 ChatSession 维护，专注和学习视图切换保留同一聊天实例。读最新消息时跟随底部，主动上翻后暂停跟随；重新排版不会被误认成用户上翻。

## 5. 紧凑布局与对话框设置

用户确认紧凑版交互预览后，将方案落实到命盘聊天。运限等共用面板继续使用原布局和快捷键；数据库仍为 v47，无新增环境变量。

### 5.1 默认布局

- 正文、用户消息和输入框默认 16px；正文行高 1.75，消息间距 14px，连续空行合并显示。
- 标题栏 48px、桌面快捷提问按钮 30px，候选事件使用紧凑数量入口；快捷键说明保留给辅助技术和发送按钮提示，不占常驻高度。
- 输入框默认一行 44px，随内容增高至最多 6 行，同时不超过聊天面板高度的 30%；删除内容后缩回一行。大字号下至少完整容纳一行。
- 正文和输入区默认铺满可用宽度；聊天容器达到 600px 时，发送按钮显示图标与文字，较窄时只显示图标。按钮保持在输入框右下角。
- 聊天小于 480px 时，工具按钮隐藏文字并保留可访问名称；移动按钮保留 44px 点击高度。手机输入字号至少 16px，仍能按设置增大。

### 5.2 设置内容与保存规则

| 分类 | 设置 |
|---|---|
| 阅读 | 聊天字号 14–22px、独立 AI 字号 14–24px、宋体/黑体、三档行距与消息间距、铺满/最大 820px 舒适阅读 |
| 输入 | 自动增高、最多 4/6/8 行、Enter 或 Ctrl/⌘ + Enter 发送 |
| 行为 | 跟随最新回复、显示快捷提问栏、事件候选默认折叠、减少消息动画 |

设置即时预览，保存后才写入当前来源的 localStorage，键名为 `ziwei-chart-chat-preferences`，含版本号和严格字段校验。取消、关闭、Escape 或点击弹窗外部均丢弃预览；“恢复默认”也需保存后才持久化。受限存储下仍应用当前设置，并提示刷新后不能保留。其他标签页通过 storage 事件同步已保存的偏好。

关闭自动跟随时，新回复不会自动滚动；明确发送或点击“回到最新消息”仍会跳到最新位置。开启时保留原有上翻暂停跟随行为。减少动画同时遵循设备偏好。中文输入法组合输入不会误发送。

弹窗使用原生 dialog，包含焦点限制、关闭后焦点返回、分类键盘切换和 Escape 取消；手机全屏显示，正文滚动且保存操作固定在底部。设置不改变 ChatSession 生命周期，生成中可调整，专注和学习模式切换保留消息与草稿。
