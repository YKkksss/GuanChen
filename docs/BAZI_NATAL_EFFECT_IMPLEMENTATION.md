# 八字原局作用复核：节气分支与近合条件

本阶段承接六项命理深化，属于 `1.1.0-dev`。用户确认先补原局规则，再推进分方法旺衰、格局取用，最后连接岁运和个人化择日。本次交付第一阶段的可核验适用条件，不宣称完整作用效力引擎已经完成。

## 页面与使用

入口为已保存八字的“八字论命总览”：`/bazi/reading/[id]`。新增“原局作用复核”，包含月内分支、五合近邻、藏根与合冲、方法与来源四个视图。每个检查项分别显示满足、不满足或待核，并解释该项具体判据。

当前调候入口随已定位的分支变化；“具体用干”仍保留章节参考全集，但标明当前分支主要参考、配合参考和其他未启用分支。查阅其他日干月支的参考索引不改变当前盘。浏览复核和来源不调用 AI。

## 月内分支

核对《穷通宝鉴》维基文库转录的固定版本 `oldid=2294674`，只改写取用条件，不采用人物评价、贫富、婚姻、健康和寿夭断语。

| 组合 | 本轮处理 |
| --- | --- |
| 乙日酉月 | 秋分前核癸；秋分起核丙及癸的配合 |
| 癸日辰月 | 谷雨前核丙；谷雨起仍核丙，并列辛甲酌用条件 |
| 乙日午月 | 上下半月两支并列，未自动选择 |
| 壬日丑月 | 上下半月及癸辛／己土主事条件并列，未自动选择 |
| 癸日未月 | 两半月的金与比劫配合条件分别保留，未自动选择 |

后面三组原文没有给出本项目可直接核验的精确分界。本轮没有把公历十五日、月长中点、夏至／大暑／大寒或另一部书的人元司令表当作其确定含义，也没有声称完整人元司令已实现。

明确的秋分、谷雨使用现有锁定版 `lunar-javascript` 的交节秒，前段不含交接时刻、后段包含交接时刻。只在保存的民用时与 UTC+08:00 一致且月支与该时刻的节令月一致时自动定位；保留原盘，不静默重排。历史上海夏令时、其他时区、真太阳时保留待核。晚子时换日不移动节气交接时刻。

未知时辰按保存出生日期的完整区间检查，不能使用中午试排时刻直接选边。整日跨月令或跨秋分／谷雨时，两支均待核；整日不跨界时可以定位章节分支，但时柱仍缺失、喜忌仍不裁定。

## 五合与藏根

五合按年、月、日、时固定位置匹配，每一对只出现一次：

- 相邻且已知对象单一，通过近合入口；这不表示已经合绊、合去或合化。
- 同一干同时面对两侧直接近邻对象时列近邻争合；不选择谁被合去。
- 隔位的同干重复不直接计作近邻争合；年干与时干远隔单列，不折算力量百分比。
- 隔位中间干克端点的五行方向列为“克隔条件待核”。这是对原典克隔例的项目条件映射，不是对任意隔干实际效力的通用裁决。
- 涉及日干时注明本身之合，不能自动推成财官被合去。
- 缺时柱不压缩柱位。已知三柱未见竞争对象不能升级为完整四柱对象唯一。

藏根针对日主、已知表干和本月参考干分别核对。完全相同藏干为严格同干根；同五行其他干只列支持参照。逐根保留其六冲、六合及完整三合位置，完整三合必须三种支齐备。根受冲仍保留原来的藏干位置，一根受冲不抹去另一未见冲的根。

“未见六冲的同干藏根”只是一项可核条件：无冲不等于强根，受冲不等于拔根；缺时支时仍待核。会合与六冲并见保留双方，不自动宣布解冲、冲开或某种关系失效。实际根气效力、全局生克先后、合化和旺衰留待后续阶段。
