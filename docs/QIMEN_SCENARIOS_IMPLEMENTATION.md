# 奇门占类取用与条件对照

2026-10-16（北京时间 UTC+08:00）。承接六爻作用路径阶段，按既定顺序继续奇门。入口 `/qimen`，数据库仍为 v56，无新增迁移；未提交或推送远程。

## 使用流程

新建占问增加独立的“占类条件复核”设置，默认暂不指定。用户可以明确选择求财体用、考试文章或水陆出行，原有日干、时干、门星及手选宫位参考仍保持独立。改变场景会取消旧预览并清空旧结果，保存时锁定表单。

预览及已保存盘面新增四个视图：

| 视图 | 内容 |
| --- | --- |
| 取用角色 | 场景角色、实际符号、原宫与寄宫、天盘落宫及比较层级 |
| 宫位条件 | 与九宫联动，查看两套月令、门宫关系、部分旬空、逐干加临和宫内格局 |
| 两侧关系 | 分别展开两侧条件，按真实生克方向展示箭头，保留同宫双角色 |
| 规则来源 | 原典章节、适用范围、待核条件及版本 |

已保存新版占问的 AI 对话增加“占类条件”快捷问题。场景、角色、关系与依据随该占问固定保存；查看宫位不会修改取用，回看不重新排盘。

## 本轮场景与比较口径

依据为[《奇门遁甲元灵经》](https://zh.wikisource.org/wiki/奇門遁甲元靈經)卷十六求财、卷八岁考与考试文章、卷十四水陆条文；同书不同分支的角色不混用。本轮只连接下表明确角色和关系，不移植原典的确定性断语、等第或个案结果。

| 场景 | 角色与比较 |
| --- | --- |
| 求财 · 生门宫星体用 | 生门所在宫为体，同宫实际九星为用；比较星自身五行与宫五行 |
| 考试 · 日干天辅文章 | 日干士子、天辅文宗、丁为文章；比较天辅宫、丁宫与日干宫的五行 |
| 出行 · 水陆条件对照 | 值使落宫与固定坎一、艮八参照；休、生两门另列辅助 |

求财的天禽随芮双星逐项保留，不擅自择一或按数量投票。考试中丁日士子与文章丁可以同符号、同宫，角色仍分别存在。水陆只作该窄分支的传统条件对照，不选择真实路线或保证出行安全。求职、一般出行、行人归期等其他分支没有借用本轮模板冒充已实现。

宫、门普通五行月令与九星专门口诀沿用既有两套口径。角色的 `comparisonBasis` 明确为 `palace` 或 `star`，同宫不强制同五行，相生或同宫也不表示事情已成。

## 干、宫与角色的条件归属

日干甲复用该日柱自身旬遁仪，保留地盘原宫、中五寄坤和天盘随星位置；不会借用时柱旬首。固定文章丁直接定位奇仪，不虚造一个干支柱。

角色的 `ownPatterns` 仅保留匹配天盘奇仪本身的击刑、三奇入墓位置；甲干按其匹配遁仪核对。门、星和固定宫位参照不继承其他天盘干的刑墓。

宫位视图保留宫内各干的全部格局上下文，名称与实际天盘干不省略。例如同宫乙入墓不能改写为日干己入墓，更不能转给天辅或生门。丁墓异文继续显示。宫内部分支时旬空，不扩张为整宫所有角色失效；门迫、宫制门、刑墓及伏反吟不会被一条相生关系自动解除。

## 快照、版本与安全

| 标识 | 版本 |
| --- | --- |
| 基础排盘 | `qimen-v1-hour-turning-chaibu-kun`，保持不变 |
| 上一版条件复核 | `qimen-reading-v1-focus-palace-door-star` |
| 新版条件复核 | `qimen-reading-v2-scenario-role-conditions` |
| 占类快照 | `qimen-scenario-v1-wealth-exam-routes` |
| 新问答 | `qimen-chat-v3-scenario-role-conditions` |

`QimenInput.scenario` 只接受明确枚举；省略与 `none` 统一为省略输入，旧 `focusTarget` 语义不变。服务端从原始时间、定局条件和明确场景计算 `reading.scenario`，客户端伪造结果或用户标识不能替换结果或跨账号写库。新快照和证据使用原 `result_json`，完整结果指纹保持新旧记录独立，无须修改数据库结构。

占类依据采用 `reading:scenario:policy`、`role:*`、`pair:*`、`palace:*`。AI 按完整新版、上一版条件盘、基础旧盘分别选择 v3、v2、v1 提示；缺失或未知占类版本仅允许原条件能力，未知条件版本退回基础盘面能力。没有占类角色时不从自由占问文本补定。

旧记录读取、问答及备份恢复都不增加新场景、不重写原盘与旧回复。账号数据库隔离、私有不缓存响应及同源写入约束沿用原实现；没有增加公开分享入口。问答继续限制 1–8 条真实保存依据，并保留失败重试、停止与幂等流程。
