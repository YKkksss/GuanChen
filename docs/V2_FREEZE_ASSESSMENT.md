# 观辰 v2.0.0 冻结评估（本地优先）

评估日期：2026-10-18。目标版本：`v2.0.0-rc.1`。交付形态：本地/局域网自托管；公网部署为可选自配置能力。

## 1. 结论

**建议先发 `v2.0.0-rc.1`，不直接打 `v2.0.0`。**

理由：本地功能、数据、安全、AI 冒烟、浏览器四宽度和 axe 均已通过；唯一没有完成的是**用户自己的 iOS/Android 真机确认**。按发布门槛，真机是关键链路阻断项，不能用视口模拟代替。

真机确认通过后，`rc.1` 不需要改代码即可转为 `v2.0.0`。

## 4. 冻结前必须完成的最后一项

请用手机在同一 Wi-Fi 下访问 `npm run local` 打印的局域网地址，确认：

1. 注册/登录。
2. 首页录入出生资料并生成命盘。
3. 打开命盘工作台，侧栏可展开。
4. 打开“账号设置”，看到 AI 服务状态。
5. 打开“数据保险箱”，能看到当前账号的备份入口。

手机型号、系统版本、是否通过，记录到 `docs/V2_DEVICE_CHECK.md`；通过后即可将 `rc.1` 转为 `v2.0.0`。

## 5. 冻结后的规则

- `v2.0.0` 之后只修 P0/P1；新规则层（五合去留等）进入 v2.1。
- 不移动 `v1.0.0` / `v2.0.0` 标签；不强推。
- 公网部署问题由用户按 P2 手册配置；不作为本地版本的阻断项。
- 真实模型质量只做抽样，不承诺全面合格。

## 6. 不做/暂缓

- 邮件找回、2FA、账号自助注销。
- 多实例、PostgreSQL/Redis、队列。
- 支付/会员、Android 客户端。
- 完整术数理论裁决树、所有流派校勘。
