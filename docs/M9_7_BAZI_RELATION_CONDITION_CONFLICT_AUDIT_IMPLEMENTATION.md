# M9-7 关系条件与冲突裁决审计实施说明

## 1. 阶段目标

M9-7 在 M9-6“发现了哪些关系”之上增加独立的二次审计层。程序回答：

- 当前关系的结构成员是否齐全；
- 天干五合的月支支持和妒合干入口条件是否通过；
- 三字关系是否仍缺一个成员；
- 参与的原局柱位是否连续相邻；
- 同一节点是否同时参与多种地支关系；
- 当前应标记为条件齐备、条件缺失、关系并见还是暂缓裁决。

本阶段的“裁决”只裁决证据状态，不裁决合化、解冲、破合、力量大小、关系优先级、吉凶或具体事件。

## 2. 独立版本层

数据链路调整为：

```text
确定性四柱
   ↓
大运排期 → 流年时间轴
   ↓
M9-6 跨层关系证据
   ↓
M9-7 条件与冲突审计
```

M9-7 不修改 M9-6 原始证据。任何条件结论都保存上游关系证据版本和指纹，因此后续方法变化不会悄悄改写旧结果。

## 3. 四种审计状态

### 3.1 可核验条件齐备

表示当前程序已经实现的入口检查全部通过。例如丙辛五合配对成立、月支位于当前版本列出的支持范围、同片段未见对应妒合干。

该状态仍不等于：

- 合化成功；
- 原五行已经消失；
- 某种关系获得优先权；
- 已经产生吉凶作用。

### 3.2 条件缺失

至少一项当前版本要求的条件未通过。例如：

- 五合配对存在，但月支不在对应支持范围；
- 三合、三会或三刑只出现两个成员，仍缺第三字。

三字缺一会保存已出现成员、缺失成员和实际时间片段，但不会进入 M9-6 的完整关系清单。

### 3.3 关系并见

同一个地支节点同时参与两种或以上不同关系，或者五合条件检查发现同片段另有规则所列妒合干。程序只保存：

- 共同参与节点；
- 并见的关系类型；
- 上游证据 ID；
- “不裁决优先级”的固定边界。

不得自动生成“合解冲”“冲破合”“某关系压过另一关系”等结论。

### 3.4 暂缓裁决

关系结构已经存在，但位置或其他尚未版本化的条件不足以形成稳定自动结论。例如多个原局参与柱位不连续时，只记录间隔事实，不采用固定力量公式。

## 4. 天干五合入口检查

首版版本化以下可程序核验条件：

| 配对 | 传统目标 | 支持月支 | 妒合干 |
| --- | --- | --- | --- |
| 甲己 | 土 | 辰、戌、丑、未、午 | 戊 |
| 乙庚 | 金 | 巳、酉、丑、申 | 甲 |
| 丙辛 | 水 | 申、子、辰、亥 | 丁 |
| 丁壬 | 木 | 亥、卯、未、寅 | 丙 |
| 戊癸 | 火 | 寅、午、戌、巳 | 己 |

这些检查来自《三命通会》卷二“论十干化气”的入口描述。程序只判断“支持月支是否出现”和“妒合干是否出现”，不采用古籍中的人物、灾福、格局高低和事件断语。

## 5. 三字缺一候选

每个真实流年片段重新建立原局、大运、流年地支节点。对三合、三会、三刑集合执行：

```text
出现 3 个不同成员 → 复核 M9-6 完整关系
出现 2 个不同成员 → M9-7 条件缺失候选
少于 2 个成员       → 不输出候选
```

候选仍必须跨越至少两个层级，避免把纯原局内部候选重复搬入动态审计。

## 6. 柱位与关系并见

### 6.1 原局柱位

- 少于两个原局柱参与：标记“不适用”；
- 两个或以上原局柱连续：记录相邻事实；
- 原局柱不连续：标记“位置影响暂缓裁决”。

动态大运、流年与原局不是同一线性柱位，不套用相邻距离权重。

### 6.2 并见聚类

以参与节点 ID 为键聚合 M9-6 地支证据。同一节点命中两种或以上不同关系类型时，生成一个并见节点。并见聚类不会删除或改写任何上游关系。

## 7. SQLite v29

新增 `bazi_relation_adjudication_versions`：

- 绑定命盘版本与 M9-6 关系审计版本；
- 保存命盘和关系审计指纹；
- 保存方法版本、引擎版本和完整结果 JSON；
- 相同上游版本与方法版本自动复用。

`bazi_conversations` 新增 `relation_adjudication_version_id`。新旧会话都会绑定 M9-7 版本，提示词升级为 `bazi-chat-relation-adjudication-v6`。

## 9. 对话上下文与输出守卫

上下文新增“权威八字关系条件与冲突审计快照”，只注入当前问题聚焦年份。

新增允许能力：

- `relation_condition_conflict_audit`。

新增禁止能力：

- `relation_priority_verdict`。

输出守卫会拦截“某合优先”“某冲被解掉”“某关系失效”等越权关系优先级结论。

## 10. 来源与边界

- [《三命通会》卷二·论十干化气](https://zh.wikisource.org/zh-hans/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83/%E5%8D%B7%E4%BA%8C)：用于五合月支支持与妒合干入口；
- [《三命通会》卷二·论支元三合](https://zh.wikisource.org/zh-hans/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83/%E5%8D%B7%E4%BA%8C)：用于三字缺一不成完整三合局的边界；
- M9-6 关系证据版本：用于关系、参与柱位和真实时间片段。

“邻近”和“关系并见”只作为项目可核对的结构元数据，不引用存在争议的固定力量排序。传统命理关系不是现代科学因果关系。
