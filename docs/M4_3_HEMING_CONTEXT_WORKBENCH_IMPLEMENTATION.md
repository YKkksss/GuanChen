# M4-3 双命盘上下文与合盘工作台实施说明

> 完成日期：2026-08-15  
> 范围：双命盘 Context Builder、持久化合盘对话、关系背景更新、双盘对照和固定高度聊天区

## 1. 阶段结果

M4-3 已把 M4-1 的双命盘持久化和 M4-2 的可审计规则引擎接入统一对话链路。合盘不再调用一次性的 `/api/heming` 临时分析：保存后的所有提问统一进入 `/api/conversations/[id]/respond`，因此用户消息、流式回答、上下文运行记录、滚动摘要和关键记忆都会写入本地 SQLite。

刷新页面或从左侧合盘历史重新打开时，双方命盘、关系背景、规则评估和完整聊天记录均可恢复。

## 2. 双命盘 Context Builder

新增 `lib/context/heming-builder.ts`，上下文按权威顺序组织：

1. 合盘系统约束：甲乙身份隔离、禁用事实、风险表达边界。
2. 双命盘程序事实：按当前关系类型只选取需要的宫位，去除姓名、地点、宫干自化等无关或禁用字段。
3. 规则引擎结果：注入规则编号、阶段、级别、置信度、结论、建议和证据编号。
4. 用户确认的关系背景：空字段保持未知，不允许模型补全。
5. 关键记忆、滚动摘要和相关旧消息召回。
6. 最近最多十轮原始对话，至少尽力保留最近四轮。
7. 当前用户问题完整置于最后。

构建器复用单盘已有的模型预算、Token 估算、最近轮次、全文检索和降级机制，并新增 `heming-context-v1` 清单，供 `context_runs` 审计每次模型调用实际使用了哪些层。

### 2.1 甲乙事实隔离

- 命盘事实固定放在 `chartA` 与 `chartB` 两个独立字段。
- 每条证据保留 `A`、`B` 或 `interaction` 归属。
- 合盘摘要要求明确写“甲方”“乙方”或“双方互动”。
- 合盘记忆无法确认人物归属时不提取，禁止把一方经历复制给另一方。
- 系统提示禁止模型交换、合并或补造任一方事实。

### 2.2 自动压缩与恢复

合盘对话沿用已经上线的上下文维护策略：当未摘要历史超过 12 轮或约 6000 Token 时，旧消息会进入滚动摘要；最近六轮在压缩时受到保护。关键事实单独提取为可编辑记忆，相关旧消息通过 SQLite FTS 按当前问题召回。原始聊天不会因压缩而删除。

## 3. 接口变更

- `POST /api/conversations/[id]/respond`：根据会话类型自动选择单盘或双命盘构建器，合盘消息使用同一套持久化流式响应服务。
- `PATCH /api/conversations/[id]`：合盘会话可更新 `relationshipType` 与 `relationshipContext`；单盘会话拒绝这些字段。
- `GET /api/conversations/[id]/heming-evaluation`：继续作为工作台的只读、确定性规则数据源。

关系类型切换时，界面会采用新关系的默认角色并清空旧类型的确认事实，避免把情侣背景误用于商业合伙等其他分析口径。

## 4. 合盘工作台

保存后的 `/heming/[id]` 现在包含：

- 可折叠的合盘历史列表。
- 可展开编辑的关系类型、双方角色、关注问题和现实确认字段。
- 按关系维度切换的甲乙双盘宫位对照。
- 区分本命基线、阶段影响和安全降级的规则结果卡片。
- 缺失现实信息提示、规则编号、证据数量和置信度。
- 固定高度、内部独立滚动的 AI 聊天区。
- 关系类型专用快捷问题、合盘总览入口和对话记忆管理。

聊天区不会随消息增长而拉长整个页面；输入区始终固定在面板底部。

## 5. 安全与产品边界

- 不输出单一匹配分数。
- 不使用宫干自化、跨盘飞化、来因宫或模型自行计算的命盘事实。
- 结构对应不直接定义为吉，结构差异不直接定义为凶。
- 本命关系基线和大限阶段影响分层展示。
- 未确认的现实经历保持未知。
- 不替用户作出婚姻、合作、医疗或财务决定。

## 6. 验证

新增 `npm run test:heming-context`，覆盖：

- 双命盘事实与角色隔离。
- 禁用字段和个人姓名、地点不进入模型上下文。
- 规则结果与未知时辰降级注入。
- 长对话最近轮次、旧消息召回和输入预算控制。
- 构建失败时的基础降级上下文。
- 关系类型与现实背景更新后立即重建权威上下文。

同时要求通过 TypeScript 类型检查、现有合盘方法论/持久化/规则引擎测试和生产构建。

## 7. 下一阶段

M4-4 将复用 M3 的版本化报告能力，开发可保存、重新生成和导出的合盘专题报告。报告应包含关系总览、支持性结构、压力点、沟通建议、边界建议、阶段影响和证据依据。
