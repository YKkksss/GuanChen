# M6-3 结构化练习、错题本与复习机制实施说明

> 完成时间：2026-08-17
> 范围：跨章节综合练习、真实命盘识别题、知识点掌握度、错题本、复习队列

## 1. 阶段目标

M6-3 将 M6-2 的“完成章节并通过小测”升级为持续学习闭环。用户答错的题目不再只停留在一次成绩中，而是自动进入错题本；系统按知识点累计作答数据，并通过复习结果更新掌握状态。

本阶段仍采用确定性评分，不接入开放式 AI 批改。

## 2. 原始记录与派生状态

原始答题记录永久保存：

- 章节小测保存在 `learning_attempts`。
- 综合练习保存在 `learning_practice_attempts`。
- 每次练习保存题目快照、用户答案和逐题评分结果。

可重建派生数据包括：

- `learning_knowledge_progress`：知识点掌握度。
- `learning_review_items`：错题和复习状态。

课程或题库版本升级时，原始题目快照仍可以解释历史成绩。

## 3. 练习类型

### 3.1 命盘结构跨章节复习

固定八道标准题，覆盖：

1. 七步读盘顺序。
2. 命宫与身宫。
3. 星曜分层。
4. 三方四正。
5. 本命四化层级。
6. 空宫借对宫。
7. 本命、大限和流年分层。
8. 传统解释和现实事实边界。

满分 100 分，75 分通过。

### 3.2 我的命盘识别练习

用户选择一份已保存的单人命盘，服务端只读取命盘快照，程序生成：

- 命宫位置题。
- 身宫位置题。
- 命宫对宫题。
- 命宫主星题。
- 命宫三方四正题。
- 命宫本命四化题。
- 空宫借对宫题（命盘存在空宫时）。
- 时间层级边界题。

题目和标准答案由程序生成，AI 不参与命盘计算。

## 4. 知识点掌握度

每道题关联一个或多个知识点。作答后累计：

- 作答次数。
- 正确次数。
- 错误次数。
- 正确率。
- 当前状态。

状态规则：

- `learning`：已开始作答但样本不足。
- `reviewing`：出现过错误且尚未达到掌握标准。
- `mastered`：至少作答 3 次，正确率不低于 80%。

掌握度属于派生指标，不替代原始答题记录。

## 5. 错题与复习状态

题目答错后按来源和题目 ID 聚合，不重复创建相同错题：

- `due`：待复习；再次答错会重置连续正确次数。
- `reviewing`：复习答对一次，次日可继续复习。
- `mastered`：连续答对两次，进入已掌握。

用户也可以手动标记已掌握，或把已掌握题目重新加入复习。

## 6. SQLite 第 16 版迁移

新增三张表：

### `learning_practice_attempts`

保存练习集 ID、关联命盘、得分、答案、评分结果和题目快照。

### `learning_knowledge_progress`

按知识点保存累计正确率和掌握状态。

### `learning_review_items`

保存错题快照、最近错误答案、错误次数、连续正确次数、下次复习时间和掌握时间。

## 7. 页面与接口

页面：

- `/practice`：练习概览、知识点掌握度和练习入口。
- `/practice/foundation-review`：跨章节综合练习。
- `/practice/chart-structure`：选择真实命盘并生成识别题。
- `/practice/review`：错题本、状态筛选和逐题复习。

接口：

- `GET /api/learning/practice/overview`
- `GET|POST /api/learning/practice/foundation-review`
- `GET|POST /api/learning/practice/chart-structure`
- `GET /api/learning/review`
- `PUT /api/learning/review/[reviewId]`
- `POST /api/learning/review/[reviewId]/attempts`

## 8. 验收与测试

`npm run test:learning-practice` 覆盖：

- 章节错误自动进入错题本。
- 知识点正确率和状态更新。
- 连续答对两次自动掌握。
- 手动重开复习和标记掌握。
- 跨章节综合题固定评分。
- 单人命盘结构题确定性生成。
- 练习题目快照和命盘关联。
- SQLite 第 16 版迁移。

## 9. 下一阶段：M6-4

下一步建设开放式解盘练习与 AI 反馈：

1. 定义开放式题目的标准答案要点。
2. 建立必须识别项、可接受表达、常见错误和分值权重。
3. 程序先完成事实核对和要点匹配。
4. AI 只在评分规则范围内解释遗漏、表达改进和推理顺序。
5. 保存评分规则版本、模型版本、反馈依据和历史尝试。
