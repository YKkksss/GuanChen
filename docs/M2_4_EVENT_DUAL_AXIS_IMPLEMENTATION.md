# M2-4 人生事件自然年份／虚岁年龄双轴实现说明

## 1. 阶段目标

M2-4 为既有的人生事件档案增加两种观察口径：

1. 自然年份轴：以公历年份为主索引，虚岁作为辅助信息。
2. 虚岁年龄轴：以虚岁为主索引，公历年份作为辅助信息。

两种口径查看的是同一批用户已确认事件，不复制数据、不修改事件日期，也不重新计算运限快照。切换只改变时间轴的组织和展示方式。

## 2. 年龄口径

年龄轴沿用当前紫微流年模块的一年一岁索引：

```text
虚岁 = 观察年份 - 出生年份 + 1
```

因此出生自然年显示为虚岁一岁，同一自然年内的事件使用同一个虚岁索引。该值用于流年档案定位：

- 不等同于按生日切换的周岁；
- 不在同一个自然年内再次按生日拆段；
- 不改变事件已经保存的公历日期；
- 不影响流年、流月、流日的确定性快照和事件回溯依据。

日期范围事件会同时展示起止虚岁，例如 `2018-03-12 至 2020-08-20` 在 1990 年出生档案中显示为 `虚岁 29–31`。日期不详事件继续保留在独立节点，不强行推导年龄。

## 3. 页面交互

人生事件页新增“时间轴口径”工具栏：

- `自然年份` 与 `虚岁年龄` 两个互斥切换按钮；
- 当前筛选结果的年份或虚岁跨度摘要；
- “快速定位”下拉框，可直接跳到某个年份或年龄节点；
- 分类筛选后，跨度摘要和快速定位选项同步收敛；
- 用户选择的轴模式保存在本机浏览器，下次打开继续沿用。

年龄轴模式下，事件卡额外显示单点虚岁或区间虚岁，避免跨年事件只看起点而误解持续范围。

## 4. 技术实现

新增纯函数模块 `lib/events/axis.ts`，统一负责：

- 自然年份到虚岁的安全换算；
- 同一年多个事件的稳定聚合；
- 日期不详节点排序；
- 当前事件集合的年份／虚岁跨度；
- 单点事件和日期范围事件的虚岁文案；
- 两种轴模式的主副标签。

页面组件只负责选择模式和渲染，不在 JSX 中散落年龄计算规则。

本阶段不增加数据库迁移和 API 参数。轴模式属于本地展示偏好，事件事实、JSON 导出和服务端筛选保持原样。

## 5. 边界处理

- 出生年前的年份不会生成有效虚岁索引；现有事件写入校验仍会提前拒绝此类数据。
- 同一年多条事件保留在同一个轴节点内，事件原有日期顺序不变。
- 日期范围会计入时间轴跨度的结束年份，但事件卡仍归入开始年份节点，避免复制同一事件。
- 日期不详事件始终排在已知日期节点之后。
- 快速定位只滚动当前页面，不修改筛选条件、事件内容或 URL。

自动化测试覆盖出生年、后续年份、出生年前无效值、同年多事件、自然年份／虚岁主副标签、区间虚岁、日期不详和完整轴跨度。浏览器验收覆盖两种模式切换、选择状态、事件卡年龄标签和快速定位选项。
