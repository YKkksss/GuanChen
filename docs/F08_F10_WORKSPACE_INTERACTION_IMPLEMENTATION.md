# F08–F10：导航、命盘工作台与点击语义

实施日期：2026-09-05（UTC+08:00）。基于 `dev` 分支 `ca763b1`，对应 AI 交接文档中的批次 A。

## 1. 交付范围

### F08：导航名称和业务目标对齐

| 入口 | 有兼容档案上下文 | 无兼容档案上下文 |
| --- | --- | --- |
| 命盘报告 | 个人、合盘或校正档案的 `/reports` | 先选择个人、合盘或校正档案 |
| 人生时间轴 | 个人命盘的 `/events` | 先选择个人命盘 |
| 运限分析 | 个人命盘或合盘的 `/timeline` | 先选择个人命盘或合盘 |
| 月度复盘 | `/reviews` | `/reviews` |

新增 `/chart/select?target=reports|events|timeline`。选择页提供加载提示、失败重试、最近档案名称筛选、无结果提示和建档入口。非法目标回退到报告选择页；`select`、`new` 不作为档案 ID。

事件入口加载最近 100 份未归档个人命盘；报告和运限入口加载个人、合盘合计最近 100 份未归档会话；报告另加载最近 100 份校正档案并排除归档项。页面明确说明筛选范围，完整历史检索仍属于后续 F15。

### F09：统一全局工作台

`/chart/[id]` 纳入 `EasternAppFrame`。保留全局品牌、功能目录和跨模块导航，原命盘页重复的品牌栏改为“命盘解读”工具栏。

- 历史对话与当前命盘工具分别作为抽屉展开，默认关闭。
- 桌面同时展示命盘和聊天，命盘内部可滚动，宫位事实及分析按钮保留在下方。
- 平板和手机使用命盘/解读视图切换；保留手机命盘总览、放大和横向阅读能力。
- 两种抽屉共用滚动锁；打开全局导航会关闭命盘抽屉；收起导航时立即禁止抽屉接收点击，避免过渡动画误触。

### F10：选中、知识和 AI 分析分离

- 点击宫位只更新本地选中状态、三方四正和本命事实。
- “AI 分析此宫”通过显式组件接口发起请求，保留 `source=palace` 和 `palaceBranch`；生成期间禁用按钮，避免重复提交。
- 共享 `InsightPanel` 的运限页同步改用明确分析按钮，避免旧的宫位状态驱动请求继续存在。
- 主星、吉曜、煞曜中已显示的星名使用键盘可操作按钮；命盘页接入原生对话框，支持关闭按钮、Esc、背景关闭和焦点返回。
- 星曜说明来自已有 `STAR_DESCRIPTIONS`。未收录条目仅展示快照事实并说明缺少基础内容，不复用旧面板中的硬编码断语。
- 学习模式下保持聊天组件挂载，切换后保留已收到消息和输入草稿。此项是本批防回归措施；F11 的统一状态源仍待下一批处理。
