# 月令取用入口深化：透干与会支分流复核

开发日期：2026-10-18，北京时间 UTC+08:00。

## 本轮功能

八字论命总览新增独立的“月令取用入口复核”，含本气与透干、会支与缺字、阻碍并列、规则来源四个视图。它把已保存月支藏干、年／月／时表干、含月支的完整三合三会，以及缺字、六合、月支六冲、天干五合和五行相克分别列为入口或条件，全部并列保留，不排名、不计分、不裁去留。

本层承接人元司令与月令分日复核，但两者相互独立：司令层只定位原典分日表段，入口层只证明某干或某组在当前四柱中的位置；入口存在不等于得令有力，会支指向的五行不等于已经合化。

## 校勘范围与规则来源

只校勘《子平真诠》两条窄条目，文献来源与项目既有《子平真诠》条目一致：

- “论用神变化”：月令所藏不一，用神随之变化。本层只据此并列本气与他藏、透与未透，不裁定谁为最终用神。
- “论杂气如何取用”：杂气须透干会支，取以为用。本层只据此把透干位置与完整三合、三会列为入口，不把六合或补字拼成会局。

原句以节录形式保存；不同版本文字、后人的具体取法、五合去留与完整合化效力均未并入本版。

## 入口与条件分类

### 本气与他藏

月支保存的每一个藏干都保留，按藏干次序分为本气、中气、余气：

- 本气：始终保留 `main_qi_entry`，未透也不删除。
- 他藏透出：年、月、时天干中见到完全同干时列为 `transparency_entry`。
- 他藏未透：保留为 `hidden_candidate`，不升级为透干入口。

### 单透与多透

同一藏干在年、月、时天干中的同干位置数为 0、1、2 以上，分别记为未透、单透、多透。日干同干只作 `dayMasterSameStem` 参照，不计为新增透出位置。多透与多个入口都不按数量加权或排名。

### 完整会支与缺字

含月支的三合、三会只有在三支齐见时才进入 `meetings` 并成为入口：

| 类型 | 组 |
| --- | --- |
| 三合 | 申子辰水、亥卯未木、寅午戌火、巳酉丑金 |
| 三会 | 亥子丑水、寅卯辰木、巳午未火、申酉戌金 |

只记录组合所指向的五行，不指定阴阳天干；`conclusion` 固定为 `target_element_only_not_transformed`。缺一支的组合进入 `incompleteMeetings`，`complete=false`、`entry=false`，不装成完整会局。六合单列于 `sixCombines`，不作为三合三会入口。

### 阻碍与相反条件

以下关系只作 `condition_pending` 并列：

- 月支六冲并见；
- 透出天干与其他表干形成天干五合（含日干）；
- 完整会支指向的五行与月令本气或透干五行相克。

不据此解冲、破合、合化、判优先级或裁去留。

## 时间与缺时

入口层只读取已保存四柱，不依赖精确交节时刻或设备时区，因此不出现司令层的时钟降级状态。出生时辰未知时：

- 状态记为 `partial_unknown_time`，标题与说明明确降级；
- 已知柱未见透出位置不能判为全盘缺失；
- 十神不输出全日唯一值（`tenGod=null`）；
- 时柱可能补充的透干位置或会支组合留待用户补时后重新计算。

## 保存、报告与问答

主要代码为 `lib/bazi/month-intake-{types,rules,engine,output}.ts`，保存于 `BaziReadingFacts.monthIntake`。完整 facts 进入原报告指纹，数据库保持 v56，无新增迁移。

当前关键版本：

| 维度 | 标识 |
| --- | --- |
| 整体 facts 方法 | `bazi-reading-v6-month-intake-review` |
| 入口层 | `bazi-month-intake-v1-transparency-meeting-routes` |
| 口径 | `ziping-zhenquan-useful-god-change-narrow` |
| 报告提示 | `bazi-reading-report-v6-month-intake` |
| 八字问答提示 | `bazi-chat-month-intake-v23` |
| 业务库 | v56，无新增迁移 |

报告能力按实际保存字段选择 v1 至 v6。第六代报告：

- 旺衰章至少引用一条 `strength:month-command:`，格局章至少引用一条 `pattern:month-command:`（沿用第五代要求）；
- 格局章还必须至少引用一条 `pattern:month-intake:`；
- 没有入口层的旧报告按实际字段回退，不借用当前复核；
- 未知入口版本或口径时，该层与全部 `:month-intake:` 依据同步从模型载荷撤回，原文不改。

连续问答 v23 在询问取用、透干、会支、三合三会、杂气、本气、去留或月令格局时带入同源入口描述；纯岁运问题不插入整份入口层。三条快捷追问只建立或打开当前命盘会话并填入草稿，不自动发送。

输出检查允许明确否定与待核表达，拦截把会支说成已合化、把缺字说成完整三合、把六合等同于三合、按入口条数排名、以入口或司令直接裁定旺衰／成败／唯一喜忌，以及给会支指定阴阳天干。
