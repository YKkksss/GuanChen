# M9-12 月令与旺衰综合条件证据审计 v2 实施说明

## 1. 阶段目标

M9-12 将原本分散在静态原局和岁运阶段的证据放入同一份可追溯矩阵：

- 原样保留 M9-3 静态旺衰证据标签；
- 提取大运、流年表层十神的生扶或泄耗制方向；
- 将岁运藏干放入“位置／条件上下文”，不冒充已经发动的力量；
- 回指 M9-10 的日主严格同干根或同五行支持条件；
- 回指 M9-11 的月令藏干触达类型与关系条件状态；
- 比较静态基线和岁运表层是同向、异向还是并见；
- 跨交运年份按真实片段分别审计。

本阶段不输出旺衰分数、百分比、最终身强身弱、力量增减、格局成败、用神喜忌、吉凶或具体事件。

## 2. 方法论依据

《子平真诠评注》将“得时不旺、失时不弱”列为独立章节，说明月令重要但不能脱离年、日、时损益和通根执一而论。《滴天髓阐微》衰旺章也强调得令仍可能受制、失令仍可能有根。

因此 M9-12 采用“并列证据”而不是“加权总分”：

```text
M9-3 静态原局基线
       ×
M9-8 岁运表层方向
       ×
M9-10 日主根气条件
       ×
M9-11 月令与藏干触达上下文
       ↓
同向／异向／并见／不完整
```

输出只说明证据之间的关系，不回答“强了多少”“弱了多少”。

## 3. 数据链路

```text
确定性命盘
  ├─ M9-3 静态旺衰证据标签
  ├─ M9-8 岁运表层／藏干十神
  ├─ M9-10 透干与根气条件
  └─ M9-11 藏干触达条件
          ↓
    M9-12 综合证据矩阵
```

M9-12 不重新排盘、不重算十神、不重新检测透根或冲合刑害，也不修改任何上游结论。

## 4. M9-3 静态基线不可改写

综合矩阵保存：

- M9-3 原始 `assessment`；
- 原始中文标签；
- 原始置信度；
- 原始边界说明；
- 每条静态月令、根气和表层证据。

静态证据仍按 M9-3 原来的方向和证据级别展示。本阶段不得因某个流年出现新表层天干，就回头修改出生原局的静态标签。

## 5. 岁运表层方向

M9-8 已确定的大运、流年表层天干十神分成两个方向：

| 十神 | 方向标签 |
| --- | --- |
| 比肩、劫财、正印、偏印 | 生扶方向 |
| 食神、伤官、正财、偏财、正官、七杀 | 泄耗制方向 |

方向标签只用于比较：

- `support_only`：岁运表层只见生扶方向；
- `drain_only`：岁运表层只见泄耗制方向；
- `both_sides`：两类方向并见；
- `none`：表层方向缺失。

这里不设置十神权重，也不将大运和流年数量相加成力量。

## 6. 岁运藏干不进入表层力量列

大运、流年地支中的藏干全部进入“条件与位置上下文”列：

- 未命中 M9-11 入口时标记为 `position_only`；
- 命中至少一类触达入口时标记为 `condition_only`；
- 同时保存藏干十神对应的理论方向，供解释角色；
- 不直接进入生扶或泄耗制证据计数。

这样可以避免把“地支中存在”“被条件触达”和“已经产生实际力量”混成同一个概念。

## 7. 日主根气条件

只提取 M9-10 中以日主天干为表层参照的根气候选：

- `exact_same_stem_root`：严格同干根条件；
- `same_element_support_only`：仅同五行支持参照；
- `hidden_support_missing`：不进入综合证据列表。

两类命中均以 `condition_only` 记录。它们位于生扶方向列，是因为条件指向日主同干或同五行支持，但仍不能解释为有效根、强根、真根或力量增强。

## 8. 月令触达复核

M9-12 从 M9-11 中只提取 `month_command_hidden_stem` 候选，汇总：

- 完全同干岁运表层触达；
- 同支重复触达；
- 明确冲合刑害关系触达；
- M9-7 关系条件状态。

月令状态：

| 状态 | 含义 |
| --- | --- |
| `multiple_touch_types` | 至少两类触达入口并见 |
| `single_touch_type` | 一类触达入口 |
| `no_open_touch_condition` | 当前开放入口未命中 |

只要存在入口，就增加“月令触达待复核”标记。程序不会自动输出月令增强、受损、失效、合化或解冲。

## 9. 静态与动态比较

允许的比较标签：

- `static_dynamic_same_direction`：静态单侧标签与岁运表层方向同向；
- `static_dynamic_different_directions`：静态单侧标签与岁运表层方向异向；
- `static_baseline_mixed`：M9-3 静态基线已经是证据并见；
- `dynamic_surface_mixed`：大运与流年表层两类方向并见；
- `partial_unknown_time`：时柱未知；
- `dynamic_surface_absent`：缺少岁运表层方向。

“同向”只说明分类方向一致，不能改写成日主变强、变弱、转旺或转衰。

## 10. 三列证据矩阵

页面按三列展示：

### 10.1 生扶方向证据

- M9-3 月令、原局根气和原局表层生扶证据；
- M9-8 岁运表层生扶方向；
- M9-10 日主根气条件。

### 10.2 泄耗制方向证据

- M9-3 月令和原局表层泄耗制证据；
- M9-8 岁运表层泄耗制方向。

### 10.3 条件与位置上下文

- M9-11 岁运藏干位置或触达条件；
- M9-11 月令触达类型与关系状态。

每条证据保存来源阶段、上游 ID、状态和边界。页面显示的条数只是列表数量，不是旺衰分值。

## 11. 跨运分段

沿用真实交运片段：

```text
交运前：静态基线 + 流年表层／藏干／条件
交运后：静态基线 + 新大运 + 流年表层／藏干／条件
```

前后片段分别形成矩阵。新大运的表层方向、藏干和月令触达不得倒灌到交运前。

## 14. 对话上下文与输出守卫

上下文新增“权威八字月令与旺衰综合条件证据快照”，只注入问题指定年份；未识别年份时聚焦当前年份。

新增允许能力：

- `strength_composite_matrix_audit`。

新增禁止能力：

- `numeric_strength_score`；
- `dynamic_strength_change_verdict`；
- `month_command_strength_effect_verdict`。

输出守卫拦截：

- 把静态动态同向／异向解释为日主变强、变弱或最终身强身弱；
- 把月令触达解释为月令增强、受损、失效或合化；
- 输出旺衰评分、百分比或类似伪精确数值。

“同向但不代表日主变强”等边界表达允许正常输出。

## 15. 来源与方法边界

- [《子平真诠评注》](https://ctext.org/wiki.pl?chapter=974137&if=gb)：用于“得时不旺、失时不弱”和月令不可执一的边界；
- [《滴天髓阐微》](https://zh.wikisource.org/zh-hant/%E6%BB%B4%E5%A4%A9%E9%AB%93%E9%97%A1%E5%BE%AE)：用于得令、通根和全局损益需结合观察的传统论述；
- [《滴天髓》体用章](https://zh.wikisource.org/zh-hant/%E6%BB%B4%E5%A4%A9%E9%AB%93/10)：用于提纲与年月时损益的体用边界；
- 项目 M9-3、M9-8、M9-10、M9-11：作为程序唯一上游事实来源。

古籍只用于说明传统术语和方法差异，不代表现代科学验证。本项目不将其用于医疗、法律、投资等高风险决策。
