# P5 真实模型冒烟与本地 AI 配置体验

日期：2026-10-18。范围：本地用户如何确认 AI 是否可用、用多少、缺什么配置；真实模型只做合成短文冒烟，不做完整报告质量评估。

## 1. 真实模型冒烟

新增 `scripts/qa-ai-smoke.ts`，命令：

```bash
npm run qa:ai-smoke
```

行为：

- 通过 `@next/env` 读取 `.env.local`，不打印密钥。
- 未配置密钥时输出 `skipped: true` 并以 0 退出，不发起请求。
- 已配置时发 4 类合成短文请求：
  1. 命盘问答边界；
  2. 八字月令/透干/旺衰与喜用边界；
  3. 报告摘要的条件与不确定性；
  4. 六爻/梅花/奇门结构不等于现实事件。
- 记录每次延迟、token 用量、内容长度与片段；检查空内容与“必定/注定/唯一用神”等越权词。
- 可选 `AI_PRICE_INPUT_PER_M`、`AI_PRICE_OUTPUT_PER_M` 估算费用；未设置则不编造金额。
- 输出 `docs/qa-evidence/2026-10-18-v2.0-p5-ai-smoke.json`。

注意：这是**供应商连通性与输出边界冒烟**，不是完整应用链路、报告校验或真实解读质量评估。

## 2. 本地 AI 配置体验

### 2.1 账号设置里的 AI 状态

`/settings/account` 新增“AI 服务”区块，通过 `GET /api/ai/status` 读取：

- 是否已配置；
- 供应商与模型名；
- 今日已用 / 每日上限（`AI_DAILY_LIMIT`，0 表示不限）；
- 密钥只在服务器 `.env.local`，页面不显示、不接收、不保存密钥；
- 未配置时明确提示：规则功能仍可用，AI 问答/报告需要部署者配置密钥并重启。

接口只返回状态与用量，不返回密钥、base URL、请求体或聊天内容。

### 2.2 配置方式

```dotenv
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
AI_DAILY_LIMIT=200
```

- 本地用户在 `.env.local` 填写后重启 `npm run local`。
- 配额按账号、按北京日期累计；失败/取消也会计入。
- 未配置或超限时，命盘、排盘、择日、备份等确定性功能不受影响。

## 3. 验收

- 真实模型冒烟：4/4 通过，0 越权词。
- 账号设置页在真实 Chrome 中渲染 AI 状态；P4 浏览器 E2E 46/46 通过，axe 0 critical/serious。
- 配额与状态接口由既有 `test:accounts`（未登录 401）与 `test:release-engineering`（配额）覆盖。
- CI 与全量回归结果见 P5 交付 JSON。

## 4. 明确不做

- 不承诺真实模型在所有报告/长上下文下都合格。
- 不做供应商账单平台或精确费用结算。
- 不把密钥放到浏览器、localStorage 或用户可编辑的页面。
- 不做模型自动切换/多供应商路由。
