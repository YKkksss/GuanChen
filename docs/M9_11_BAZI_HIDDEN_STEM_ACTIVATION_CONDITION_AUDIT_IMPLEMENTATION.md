# M9-11 岁运藏干引动条件证据审计实施说明

## 1. 阶段目标

M9-11 在 M9-6 至 M9-10 的版本化证据链上，增加逐个藏干位置的“触达入口”审计：

- 检查同片段是否出现完全同干的大运或流年表层天干；
- 检查同一地支是否在不同节点重复，并要求至少一方属于岁运；
- 检查藏干所在支是否参与明确的冲、合、刑、害关系证据；
- 对冲合刑害保留 M9-7 的条件齐备、缺失、并见或暂缓状态；
- 同时展示单类触达、多类触达并见和未命中开放条件。

本阶段使用“藏干引动条件证据审计”作为传统术语名称，但程序输出统一称为“触达条件”。触达不等于藏干已经引动、发动、透出、冲开或产生作用。

## 2. 为什么不直接输出“已经引动”

公开古籍对不同地支关系是否必然产生“动”并非同一口径。《滴天髓》地支章强调冲的重要性，同时明确刑、害存在“动不动之异”；《子平真诠评注》又记录刑冲会合可能相解、不能相解或反得刑冲。

因此程序采用两层模型：

```text
可观察的触达入口
  ↓
保存上游证据与条件状态
  ↓
有效性、先后、力量和结果继续暂缓
```

这样既能回答“这个藏干被哪些结构条件碰到”，又不会把有争议的流派判断伪装成确定事实。

## 3. 数据链路

```text
确定性四柱与实际藏干
   ├─ M9-6 跨层干支关系证据
   ├─ M9-7 关系条件与并见状态
   ├─ M9-8 岁运表层／藏干位置
   ├─ M9-9 完全同干重复簇
   └─ M9-10 透出与根气条件
            ↓
      M9-11 藏干触达入口审计
```

M9-11 不重新排盘、不重新生成藏干、不重新检测冲合刑害。任何入口都必须能够回指对应的上游版本。

## 4. 入口一：完全同干岁运表层

对每个藏干检查同一真实时间片段中的大运、流年表层天干：

```text
原局藏癸 + 大运表层癸：命中完全同干岁运表层触达
原局藏癸 + 原局表层癸：不构成当年岁运入口
原局藏癸 + 流年表层壬：不满足完全同干
```

命中时必须同时满足：

1. 表层位置属于大运或流年；
2. 表层天干与目标藏干完全同字；
3. 二者属于同一实际时间片段；
4. 能回指 M9-9 同干簇；
5. 能回指 M9-10 对应藏干的透出条件候选。

这一入口仍不能被表述为“透干有效”或“藏干已经发动”。

## 5. 入口二：同支重复

同支重复要求：

- 两个不同节点出现相同地支；
- 至少一个节点属于大运或流年；
- 目标藏干必须实际存在于其中一个节点；
- 同一节点内的多个藏干不能互相制造“同支重复”。

例如原局月支为子、流年支再次为子时，月支每个实际藏干都会获得“同支重复触达”入口。但该入口只说明两个节点同支，不自动解释为伏吟吉凶、力量叠加或事件重演。

## 6. 入口三：明确冲合刑害关系

当前纳入的地支关系类型：

- 六合；
- 六冲；
- 六害；
- 子卯刑、自刑；
- 三合、三会、三刑。

入口必须来自 M9-6 的明确地支关系证据，且关系参与者中必须包含目标藏干所在节点和至少一个动态节点。每条关系同时保存：

- M9-6 `sourceEvidenceId`；
- M9-7 `decisionId`；
- 关系类型和标签；
- 条件状态；
- 参与节点。

“关系并见”不会被强行改写成某一种关系优先；“条件缺失”也不会被删除。页面和上下文会如实展示上游状态。

## 7. 逐藏干而非逐地支

同一个地支可能包含本气、中气和余气。M9-11 为每个实际藏干分别建立候选：

```text
寅藏甲、丙、戊
  ├─ 甲的三类入口
  ├─ 丙的三类入口
  └─ 戊的三类入口
```

地支关系触达时，三个藏干都可以回指同一条支关系，但程序不会据此宣告三者同强、同时发动或作用相同。

原局月支藏干继续单列为“月令藏干”，这里只是范围标签，不附加月令权重。

## 8. 状态与计数

每个藏干候选只有三种状态：

| 状态 | 含义 |
| --- | --- |
| `multiple_touch_conditions` | 至少两类入口同时命中 |
| `single_touch_condition` | 只有一类入口命中 |
| `no_touch_condition` | 当前三类开放入口均未命中 |

计数仅用于页面汇总，不能相加成力量分数、引动概率或事件概率。

“未命中”也只表示当前版本没有找到这三类入口，不等于藏干永远不动、无力或没有意义。

## 9. 跨运分段

M9-11 继承真实交运片段：

```text
交运前：原局 + 流年
交运后：原局 + 新大运 + 流年
```

交运前片段中不得出现新大运藏干、同支节点或关系证据；交运后的证据也不得倒灌到前段。

## 13. 来源与方法边界

- [《滴天髓》地支章](https://zh.wikisource.org/zh-hans/%E6%BB%B4%E5%A4%A9%E9%AB%93/03)：用于核对冲与刑害“动不动”差异，支持本阶段不统一裁决有效发动；
- [《子平真诠评注》论刑冲会合解法](https://ctext.org/wiki.pl?chapter=974137&if=gb)：用于核对刑冲会合可能并见、相解或反得刑冲，支持保留条件状态与冲突；
- 项目 M9-6／M9-7：用于地支关系证据及条件状态回指；
- 项目 M9-9／M9-10：用于完全同干岁运表层入口回指。

古籍文本用于界定传统术语与争议，不代表现代科学验证。本项目不把命理推断用于医疗、法律、投资或其他高风险决策。
