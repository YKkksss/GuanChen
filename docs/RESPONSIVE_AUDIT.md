# 平板/手机响应式检查记录

日期：2026-10-18。范围：本地真实 Chrome，登录后遍历 37 个页面，7 个宽度，共 **259 项检查**。

## 1. 检查方法

- 隔离临时账号数据：合成账号、紫微命盘、合盘、八字档案。
- 宽度：**320 / 360 / 390 / 414 / 768 / 834 / 1024**。
- 页面：首页、命盘入口/选择、历史档案、合盘入口、校时、八字入口与八字论命、合参、择日、梅花、六爻、奇门、学习、练习（含复习/开放/基础/结构）、案例（列表/新建/对比）、知识库、典籍、复盘、提醒、账号设置、数据保险箱、隐私、使用说明，以及命盘工作台、命盘事件/时间轴/日历/运程/报告、合盘工作台。
- 每项检查：
  - HTTP 状态；
  - 页面级横向溢出；
  - 可见元素越出视口（排除隐藏抽屉、装饰图、横向滚动容器）；
  - 控制台错误、页面异常、失败 API。
- 关键页面截图：320 / 390 / 768。

## 3. 检查中发现并修复的问题

| 问题 | 位置 | 修复 |
| --- | --- | --- |
| 320/360 合盘双方卡片宽 332/362，超出视口被裁切 | 合盘入口 | 窄屏单列 `minmax(0,1fr)`、卡片/表单减 padding、`min-width:0` |
| 390 合盘头部“返回/合盘分析/历史”被压成竖排 | 合盘入口头部 | 禁止换行、窄屏隐藏说明文案、缩小 padding/gap |
| 768 合盘双列表单过窄 | 合盘入口 | ≤900px 改单列，表单恢复可读宽度 |
| 390 历史档案“名称或姓名”竖排、搜索框只剩一条 | 历史档案筛选 | 手机改两列网格：搜索占整行、类型/状态各半、按钮整行 |
| 时间轴打开即自动生成年度报告，无 AI 时出现 500 | 命盘时间轴 | 进入页面只读取已有报告；改为用户点击“生成年度报告”才调用 AI |
| 登录页未水合时原生表单可能以 GET 提交，把密码带进 URL | 登录/注册表单 | 水合完成前禁用输入/提交；仍由 React 阻止默认提交 |

## 4. 已知的刻意行为

- 320–390 的紫微十二宫使用**横向平移**展示，页面本身无横向滚动；界面有“左右滑动可查看完整十二宫”提示。
- 首页轨道装饰图超出视口但被父容器裁切，不影响布局。
- 真机（iOS/Android）仍需用户按 [V2_DEVICE_CHECK.md](V2_DEVICE_CHECK.md) 确认；本记录是桌面 Chrome 的多视口验证。
