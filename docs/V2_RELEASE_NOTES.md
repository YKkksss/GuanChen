# 观辰 v2.0.0-rc.2 发布说明（草案）

发布日期：2026-10-18。版本：`2.0.0-rc.2`。交付形态：本地/局域网自托管。公网部署由用户自行配置。

## 1. 这个版本是什么

`v2.0.0` 是观辰第一个统一账号、多用户隔离、可在自己电脑上启动的版本。相对 `v1.0.0`：

- 所有页面与业务 API 需要登录，数据按账号隔离。
- 数据目录从单一 SQLite 变为 `ACCOUNT_DATA_DIR/accounts.sqlite + users/<uuid>/ziweidoushu.sqlite`。
- 业务库从 v47 迁移到 v56。
- 新增八字、合参、择日、梅花、六爻、奇门、校时、学习、案例、提醒、报告与 PDF 的当前能力。
- 提供本地一键启动、局域网访问、备份恢复、AI 配额与状态展示。

## 2. 快速开始

```bash
git clone --branch release/2.0 https://github.com/YKkksss/GuanChen.git
cd GuanChen
npm ci
npm run local
```

终端会打印本机与局域网地址；手机同 Wi-Fi 访问局域网地址。首次打开 `/register` 注册。AI 需要在 `.env.local` 配置供应商密钥后重启，账号设置页可查看状态。

## 3. 不兼容变化

| 变化 | 说明 |
| --- | --- |
| 登录要求 | v1 的匿名访问不再适用 |
| 数据布局 | 从 `data/ziweidoushu.sqlite` 迁移到账号目录 |
| 数据库版本 | v47 → v56 |
| 部署形态 | 单机工具 → 本地集中后端；公网可选 |

**v2 数据不能直接交给 v1 代码运行。** 回退必须使用升级前备份 + 对应旧代码。

## 4. 升级 v1 资料

1. 备份 v1 的 `data/` 与报告附件。
2. 启动 v2，注册一个空白账号。
3. 停止服务，在部署电脑执行：

```bash
npm run accounts:manage -- import-legacy 目标用户名
```

4. 重新登录，核对命盘、聊天、报告与附件。原库与旧备份继续保留。

## 5. 本轮新增/强化的能力

- 本地一键启动 `npm run local`，自动生成 `.env.local`、构建、打印局域网地址。
- 页面账号隔离、管理员、登录限额、会话撤销。
- 月令取用入口（本气/透干/会支）与司令分日。
- AI 状态接口与账号设置展示；每账号每日 AI 配额 `AI_DAILY_LIMIT`。
- 管理员本地一次性密码重置。
- 在线备份、恢复演练、v47→v56 迁移演练。
- 浏览器四宽度 E2E、axe、健康检查、结构化日志、CI。

## 7. 已知限制

- **真机待确认**：iOS/Android 尚未用真实设备验收；这是 `rc.2` 不直接升 `v2.0.0` 的原因。
- 没有邮件/短信找回密码、2FA、账号自助注销；提供管理员本地重置密码。
- 单 Node 进程；不承诺多实例、队列、PostgreSQL/Redis。
- 公网 HTTPS、域名、离机备份、监控由用户自行配置；文档与模板已提供。
- 真实模型只做冒烟与抽样，不承诺所有报告/长上下文质量。
- 术数规则仍有明确边界：五合去留、完整合化、六爻三合墓绝反伏吟、奇门暗干长生、梅花外应等未完成。
- 自动备份的浏览器触发逻辑仍存在；运营级备份请使用服务器定时任务。
