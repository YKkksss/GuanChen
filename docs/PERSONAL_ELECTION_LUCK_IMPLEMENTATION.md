# 个人化择日岁运背景实施记录

2026-10-16（北京时间 UTC+08:00）：承接分方法旺衰、格局与取用复核，在已有 `/election` 个人化择日中加入可选岁运背景。本阶段已完成开发及下述验证，数据库仍为 v56，无新增迁移；未提交或推送远程。

## 使用流程

1. 在择日工具勾选“加入个人八字条件”，选择当前账号一至两位不同出生档案的已保存八字版本。
2. 勾选“加入岁运背景复核”。不开启时继续使用原局关系及原有人工筛选条件，不增加岁运切段。
3. 筛选后展开日期的个人条件及“岁运背景复核”，逐人查看大运、立春流年、节令流月与时间分段。
4. 查看当日时辰，核对实际时段的背景及用事时与各层的关系。多人交运切点共同拆分时段，每位仍使用自己的排期。
5. 保存方案、日期及最多三个时段。历史回看沿用当时的版本和依据；删除来源八字后仍可从原方案快照新增时段。

岁运背景默认关闭，只展示复核依据。黄历候选、待核、事项忌和未列明状态继续保留；原有年支／日支避冲及人工五行过滤仍由用户明确开启。背景关系不会新增排除、升级候选或按数量评分。

## 规则与时间口径

### 三层背景和角色

- 大运消费已有起运排期器，记录八步干支及实际交接区间。出生前、出生时刻待核、首运前、当前大运、八步排期之外与精确归属不可用分别展示，不循环或延长大运。
- 流年按精确立春时刻换年；流月按十二节交接时刻换月，不以农历初一、公历月首或中气代替。
- 用事日干、用事时干及每层背景天干的十神，统一相对所选原盘日主定位，只表示表干角色。本轮没有将背景藏干角色、透出、引动或旺衰效力推定为成立。
- 背景层之间及与每位原局的关系，复用 M9-6 既有关系目录，展示五合、六合、六冲、刑害及完整三合、三会等结构；不重新枚举或拼接双方原局。
- 用事日或时与每一背景层另外核对五合、六合、六冲和同支。用事时没有伪装成 M9 的流日节点，日时两柱关系也不冒充完整多层作用裁决。

结构关系、十神与分方法取用是不同依据。存在五合不等于合化，有冲不等于冲开，三合齐支不等于成局，同支不等于伏吟；不凭关系数量判断旺衰、吉凶或事件。

### 精确分段

用事时间统一为北京时间固定 UTC+08:00，所有区间包含起点、不包含终点。日期结果按当日实际交节、立春、出生及交运边界拆段；时段结果合并原有早晚子时、其他时辰及交节切点，再并入所有参与者可信的出生和交运秒界，保持覆盖连续、无重叠。

例如既有排期器的合成校验命盘于 `2030-12-12 06:51:00` 进入首运，该日 `06:51:00` 之前和起点之后分别展示首运前与新运，不能以正午或整日代表值覆盖。若另一位在同日不同时间交运，两个切点均保留。

晚子仍保留原黄历日／时换日差异：个人日条件取本公历日干支，时条件取实际时干支。本轮没有把它们冒充所选原盘晚子口径下的流日；原盘时间标准和晚子口径继续显示在依据中。

### 缺时、历史时差和出生边界

- 出生时辰未知，不保存暂定序列作为精确大运；原局缺少时柱，出生当日保留出生时刻待核。日历流年、流月可以展示，不补出精确起运。
- 精确起运本轮仅接入 `Asia/Shanghai` 下唯一且偏移为 UTC+08:00 的出生民用时。历史夏令时、回拨重复时间、不存在的民用时间及其他未校准时区，均撤回精确大运归属。
- 民用时间的唯一性复用时间服务的 UTC 候选解析；不能仅因按 +08:00 回读成功就认为没有回拨歧义。`1991-09-15 01:30` 的上海民用时存在两个有效偏移，专项确认不输出精确大运。
- 真太阳时原盘继续使用保存的四柱；起运以民用出生瞬间计算，不再次校正用事时间。只有民用时间唯一且为东八区、年柱和月柱与排期器一致时才保留精确排期；跨节冲突或已保存转换歧义时撤回。
- 时区不支持时，不直接把来源本地生日当成东八区绝对出生瞬间。来源生日前一日至后一日为保守待核窗口，窗口内只展示日历干支及形式角色；窗口之前不作个人岁运关系适用判断。
- 对可确认的出生前片段，以及出生时刻未定的片段，撤回个人背景关系及用事与背景关系；日历干支和形式十神不代表该人当时已有经历。

这些撤回只限制精确大运归属或个人适用判断，不把不确定内容改写成确定结论。

## 快照、旧版与账号边界

| 标识 | 本阶段版本 |
| --- | --- |
| 个人化择日 | `personal-election-v2-luck-background` |
| 岁运背景 | `personal-election-luck-v1-exact-background` |
| 启用岁运的时段分界 | `almanac-hours-v2-personal-luck-boundaries` |
| 兼容的原个人化方案 | `personal-election-v1-relations-manual-elements` |

岁运最小快照保存出生日期及有依据的出生时刻、日主干、晚子口径、排期状态和警告、八步干支及区间，以及大运、关系和十神各自的方法与引擎版本；复用原个人快照中的四柱。未附带完整出生输入、地点、经纬度或档案备注。

新建、预览和保存只接受当前账号的来源版本标识及显式条件，由服务端读取命盘，不信任客户端提交的出生时刻、盘面、排期或结果。匿名请求返回 401，跨账号或不存在的来源／方案返回 404，敏感响应保持 `private, no-store`，写入沿用同源约束。

历史时辰接口只接收 `{planId,date}`，新筛选接口接收 `{input,date}`，两者不混用。来源删除后历史方案仍可查看，新增时段从方案保存的四柱和排期计算；重新预览或建立方案必须重新选择可用来源，不能冒用旧快照。

已选时段、日期结果和旧报告不因改备注、增选时段或读取而悄悄更新。v1 方案可继续回看及新增原规则时段，不自动开启或补写岁运背景；未知或不匹配的背景版本拒绝用当前规则新增时段，原已存依据保留。
